# internal/ — 비공개 작업 공간

**이 디렉터리는 웹에 배포되지 않습니다.**

| | |
|---|---|
| 배포되는 것 | `public/` 안의 파일만 |
| 이 디렉터리 | `public/` 밖 + `.vercelignore` 에 명시 |

> ⚠️ **저장소를 private 으로 바꿔도 `public/` 안에 넣은 파일은 웹에 공개됩니다.**
> 저장소 공개 여부와 사이트 공개 여부는 별개입니다. 비공개로 둘 것은 반드시 여기에 두세요.

## 파일

| 파일 | 내용 |
|---|---|
| `MASTER-PLAN.md` | 전체 계획과 설계 판단 근거 |
| `tasks.json` | 액션 아이템 — **진행 상태의 원본** |
| `plan.html` | 진행률 보드 (로컬 전용) |

## 보는 법

```bash
make plan     # http://127.0.0.1:8900 로 진행률 보드가 열립니다
```

`plan.html` 을 파일로 직접 열면(`file://`) 브라우저가 `tasks.json` 읽기를 막습니다.
반드시 `make plan` 으로 여세요.

## 상태를 바꾸는 법

`tasks.json` 이 원본입니다. 보드에서 체크한 것은 **브라우저에만** 남습니다.

보드에서 상태를 바꾼 뒤 **「변경사항 복사」** 를 눌러 그대로 붙여주시면,
제가 `tasks.json` 에 반영하고 커밋합니다. 그래야 다음에 열어도 남아 있습니다.
