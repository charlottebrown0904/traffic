# Admin 탭 — 우리가 아는 것을 한곳에

2026-09-12 지시: "Admin 전용 탭(탭 이름 'Admin')을 만들어 주세요. 가이드 왼쪽
옆 — 거기에 산출식과 데이터베이스 기반 내용, 판단 근거, 논문 숫자, 실거래 숫자,
필지 분석 정보, 감정평가서 준비 현황 및 보완 등 모든 내용을 자세히 기입합니다.
제목 / 간략 내용 형태로 작성 후 클릭하면 완벽히 자세한 내용 볼 수 있도록
(admin만 조회 가능)."

주소는 `/admin`. 머리띠에서 **지도 다음, 가이드 앞**에 섭니다.

## 화면 모양

접힌 상태가 `제목 / 간략 내용` 이고, 누르면 자세한 내용이 열립니다
(`<details>` 하나가 카드 하나). 카드는 여섯 묶음 열여섯 장입니다.

| 묶음 | 카드 |
|---|---|
| 값을 어떻게 내는가 | 산출식 다섯 마디 · 그 밖의 요인 · 개별요인 격차율 표 · 표준지 벌점 |
| 필지 진단 | 레이더 여섯 축 · 필지 특성(도로접·형상·지세) |
| 판단 근거 | 다섯 가설 판정 · 선행연구 숫자 |
| 자료 | 데이터베이스 현황 · 실거래 숫자 · 개발 한도와 조례 |
| 감정평가서 | 원장 현황 · 보완 계획 |
| 운영 | 공개/감춤 정책 · 등급과 자물쇠 · 한도와 비용 |

## 자물쇠 — 세 겹

**화면 코드는 자물쇠가 아닙니다.** `/admin` 의 HTML·JS 는 주소를 알면 누구나
받아 볼 수 있습니다. 그래서 세 겹으로 막습니다.

1. **화면** — `admin.js` 가 `SBUtil.me()` 로 로그인을 확인하고
   `accessOf(profile).admin` 이 아니면 안내만 냅니다. 편의입니다.
2. **비공개 버킷** — 격차율 지수 표는 `premium/valuation.json` 에서 옵니다.
   로그인 토큰과 `premium_ok` 가 맞아야 내려갑니다 (0004).
3. **관리자 전용 집계** — 원장 숫자는 `appraisal_admin_stats()` 가 줍니다.
   `security definer` 함수이고 **안에서 `is_admin()` 을 다시 봅니다**.
   집계만 나가고 원본 행은 나가지 않습니다 (0008).

`appraisal_case`·`appraisal_factor` 는 RLS 만 켜고 **정책을 그대로 두지
않았습니다** — 원본 행은 여전히 service key 로만 읽힙니다. 관리자에게도 행을
열지 않은 이유는, 화면 하나가 새면 원장 전체가 새기 때문입니다.

## 이 화면에 숫자를 적지 않습니다

**적는 순간 공개입니다.** 그래서 `admin.js` 에는 "무엇을 어떻게 하는가" 라는
설명만 있고, 숫자는 실행할 때 가져옵니다.

| 숫자 | 어디서 |
|---|---|
| 격차율 지수·면적 규칙·특례 | 비공개 버킷 `premium/valuation.json` |
| 그 밖의 요인 칸 수·원장 건수 | 같은 파일 |
| 원장 현황·검산·지역별·칸별·빈 칸 | `appraisal_admin_stats()` (관리자만) |
| 실거래·영업소·행정구역 건수 | `/app/data/meta.json` (이미 공개) |
| 가설 판정 β·p·구간 | `/app/data/verdicts.json` (이미 공개) |
| 법령 상한·조례 | `/app/data/zoning-limits.json` (이미 공개) |
| 논문 수치 | 이 저장소 `docs/literature.md` (이미 공개) |

`scripts/test_access.py` 5절이 이것을 검사합니다 — `admin.js` 에 소수점 둘
이상 숫자(1.00·1.000 제외)가 박혀 있으면 실패합니다. 새 카드를 더할 때도
숫자는 버킷이나 집계에서 받으십시오.

## 머리띠의 Admin 링크

모든 쪽의 머리띠에 `<a href="/admin" data-admin-link hidden>Admin</a>` 자리가
있고, `lib/adminnav.js` 가 `localStorage['toji-admin']` 힌트를 보고 보입니다.

가이드처럼 로그인 연결을 아예 안 부르는 쪽에서도 링크가 서야 해서 힌트를
씁니다. 힌트를 손으로 바꿔도 **링크만** 보입니다 — `/admin` 은 자기가 다시
확인하고, 숫자는 위의 세 겹을 통과해야 나옵니다. 지도·계정 화면이 로그인
상태를 알 때 `tojiAdminNav(acc.admin)` 으로 힌트를 갱신하고, 관리자가 아니면
지웁니다 (로그아웃한 브라우저에 메뉴가 남으면 안 됩니다).

## 새 카드를 더할 때

`public/admin/admin.js` 의 `CARDS` 배열에 `[묶음, 제목, 간략 내용, 자세히]`
한 줄을 더합니다. `자세히` 는 `ctx` 를 받아 HTML 문자열을 돌려주는 함수이고,
`ctx` 에 `meta · verdicts · zoning · val · stats · acc` 가 들어옵니다.
헬퍼로 `table()` · `kpi()` · `idxTable()` 이 있습니다. 한 칸이 터져도 그 카드만
빨갛게 표시되고 나머지는 그려집니다.
