# 대안 축 — 공시지가 (대표님 지시 3번, 착수 전)

실거래 표본이 끝내 얇으면 **가격 축을 공시지가로 갈아끼운다.**
아직 착수하지 않았고, 이 문서는 착수 시점에 헤매지 않기 위한 정리다.

## 왜 유효한 대안인가

실거래는 **그 해에 팔린 땅만** 보인다. 안 팔리면 관측 자체가 없다. 그래서
셀당 최소 거래건수 조건에서 대부분의 칸이 떨어져 나간다.

공시지가는 **모든 필지에 매년 매겨진다.** 표본 문제가 원천적으로 없다.
영업소 하나에 붙는 필지가 수백 개고, 매년 값이 있으므로 밴드×연도 셀이
비지 않는다.

## 대신 이런 한계가 있다

- **실거래가 아니라 평가액이다.** 시세 반응이 한 박자 늦다. 교통량이 오른
  해에 바로 반응하지 않고 이듬해 공시에 반영될 수 있다. 시차를 1년이 아니라
  1~2년으로 놓고 둘 다 봐야 한다.
- **평가 자체가 인근 실거래를 참고한다.** 가격이 오른 곳을 평가가 따라간
  것인지, 우리가 보려는 인과인지 구분이 흐려진다.
- 결론을 낼 때 "실거래 기준" 인지 "공시지가 기준" 인지 반드시 밝혀야 한다.
  둘을 섞어 말하면 투자자에게 잘못된 인상을 준다.

## 두 갈래 원천

| | 표준지 | 개별 |
|---|---|---|
| 대상 | 전국 약 50만 필지 (대표 표본) | 전 필지 (약 3,900만) |
| 성격 | 감정평가사가 직접 평가 | 표준지를 기준으로 산정 |
| 양 | 다루기 쉬움 | 매우 큼 |
| 데이터셋 | [15004246 표준지공시지가](https://www.data.go.kr/data/15004246/fileData.do) (SHP·CSV 파일) | [15029071 전국개별공시지가 표준데이터](https://www.data.go.kr/data/15029071/standard.do) |

**표준지부터 시작한다.** 50만 필지면 밴드별 표본이 충분하고, 평가 방식이
전국에서 일관돼 연도 간 비교가 깨끗하다. 개별공시지가는 필지 수가 너무 많아
지오코딩·공간조인 비용이 크고, 표준지를 기준으로 파생된 값이라 정보가
겹친다.

## 받아오는 길이 두 갈래다 (2026-09-01 확인)

착수 전에 미리 알아본 결과, 길이 두 개고 성격이 정반대다.

### 갈래 A — 파일 (15004246 표준지, SHP/CSV)

`www.data.go.kr` 의 파일 다운로드다. 이 컨테이너에서 열어보려 했으나
외부망 정책에 막혀(`connect_rejected`) 확인하지 못했다. 교통량 파일과
같은 상황이므로, **대표님이 내려받아 올려주시는 경로**가 된다.

대신 이 길에는 큰 이점이 있다. SHP 에는 **좌표가 들어 있다.** 지오코딩
대기열이 통째로 사라진다. 지금 실거래 쪽에서 하루 4,000건씩 며칠을
잡아먹는 그 단계가 없어진다는 뜻이다.

### 갈래 B — API (15029071 개별공시지가 표준데이터)

공공데이터활용지원센터가 파일데이터를 자동으로 API 로 바꿔주는 경로다.
호스트가 우리가 쓰던 `apis.data.go.kr` 이 아니라 **`api.odcloud.kr`** 이고,
주소 모양은 `https://api.odcloud.kr/api/15029071/v1/{uddi}` 다.
쓰려면 `RELAYED_HOSTS` 에 이 호스트를 넣어야 한다.

그런데 이쪽은 **좌표가 없다.** PNU·지번으로만 온다. 결국 지오코딩을
다시 타야 하고, 필지 수는 실거래보다 훨씬 많다. 지금 병목을 그대로,
더 큰 규모로 다시 겪는 길이다.

### 그래서 A 를 택한다

좌표가 있느냐 없느냐가 갈랐다. 실거래 축이 막힌 이유가 표본이었다면,
공시지가 축이 막힐 이유는 지오코딩 처리량이다. A 는 그 둘을 다 피한다.
B 는 A 가 어떤 이유로든 안 될 때의 예비다.

## 확인해야 할 것 (착수 시)

1. 15004246 이 **연도별**로 받아지는가. 우리는 변화량을 보므로 한 해만으로는
   쓸 수 없다. 파일 데이터라면 연도마다 따로 받아야 할 수 있다.
2. 좌표가 들어 있는가. SHP 로 제공된다면 좌표가 있으니 지오코딩이 필요
   없다 — 이것만으로도 실거래 대비 큰 이점이다.
3. 용도지역 필드가 있는가. 계획관리·생산관리·자연녹지 필터를 그대로 적용할
   수 있어야 한다.
4. ~~해외 IP 차단 여부.~~ **확인됨** — 막힌다. 위 갈래 A 대로 대표님이
   받아 올려주시는 경로로 간다.
