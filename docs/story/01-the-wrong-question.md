## 왜 단순 상관이 함정인가

세 가지를 표로 정리해 드렸습니다.

| 함정 | 무슨 일이 일어나는가 |
|---|---|
| **교란변수** | 교통량 많은 영업소는 대부분 수도권·대도시 근처다. 수도권 땅값은 교통량과 무관하게 비싸다. `교통량 수준 ↔ 가격 수준` 회귀는 사실상 **`수도권 더미 ↔ 가격`** 을 잰다. R² 는 높게 나오지만 "서울 근처 땅이 비싸다" 이상은 아니다 |
| **역인과** | 개발이 먼저 되어 사람이 몰리면 교통량이 는다. 교통량이 땅값을 올린 게 아니라 **땅값(개발)이 교통량을 만든** 경우가 많다 |
| **구성 변화** | 어떤 해에 대형 공장부지 1건이 거래되면 평균 ㎡당 가격이 급변한다. 가격 지표가 **"그 해 어떤 물건이 거래됐는가"** 에 오염된다 |

```mermaid
flowchart LR
    A[수도권 입지] --> B[교통량 많음]
    A --> C[땅값 비쌈]
    B -.->|우리가 보고 싶은 것| C
    style A fill:#FBE7E7,stroke:#E06666
```

> **Claude**
> 화살표 점선이 우리가 재고 싶은 것인데, 실선 두 개가 그것을 통째로
> 가립니다. 이 그림에서 점선을 0 으로 만들어도 회귀는 여전히
> "유의함" 을 냅니다.

## 교정된 가설 다섯

수준과 수준을 붙이는 것을 버리고 **변화량과 변화량**을 붙이기로 했습니다.

### H2 — 핵심

```
Δln(P_ibt) = α + β_b · Δln(T_i,t-1) + γ·X_ibt + δ_t + μ_시군구 + ε
```

| 항 | 뜻 | 왜 필요한가 |
|---|---|---|
| `Δ` | 차분 | 수준에 붙은 지역 효과를 통째로 뺀다 |
| `δ_t` | 연도 고정효과 | 전국 부동산 사이클 제거 |
| `μ` | 시군구 고정효과 | 지역 수준 차이 제거 |
| `t-1` | 1년 시차 | 반영 시간 + **역인과 일부 차단** |
| 클러스터 SE | 영업소 단위 | 같은 영업소 관측끼리 상관 |

### H3 — 거리 감쇠 곡선 · **그리고 위약 밴드**

여기가 이 프로젝트에서 가장 중요한 설계였습니다.

| 밴드 | 기대 | 역할 |
|---|---|---|
| 0–3 km | β 최대 (IC 프리미엄) | |
| 3–5 km | 감소 | |
| 5–10 km | 약함 | |
| **10–20 km** | **≈ 0** | **위약 검정 — 분석이 제대로 됐는지 보는 대조군** |

> **Claude**
> 10–20km 에서도 β 가 크게 나오면 그건 IC 효과가 아니라 지역 효과입니다.
> **이 밴드는 가설을 검증하는 자리가 아니라 우리를 검증하는 자리입니다.**

이 한 칸이 3막에서 프로젝트 전체의 방향을 바꿉니다.

### 나머지 셋

| | 내용 | 비고 |
|---|---|---|
| **H1** | 수준-수준 상관 | 참고용. **제품 근거로 쓰지 않는다** |
| **H4** | 차종 분해 — 1종(승용) vs 3~5종(화물) | 화물차가 진짜 알파일 가능성. 승용 교통량은 이미 모두가 아는 정보지만 화물 증가는 시장이 늦게 반영한다 |
| **H5** | 산업단지·택지지구 이벤트 스터디 | **교통량 시계열이 전혀 필요 없다** — 2막의 보험이 된다 |

## 그리고 그날, 교통량 API 를 파다가

엔드포인트는 찾았습니다.

```
odtraffic/trafficAmountByUnit    영업소별 교통량
  → "필수요청 파라메터(집계시간단위구분코드)가 없습니다"
odtraffic/trafficAmountByRoute   노선별
  → "시작영업소 값이 없습니다"
```

필수 파라미터 하나는 맞혔습니다(`sumTmUnitTypeCode`). `기준시` 는
후보 10개를 다 틀렸습니다.

```
stdHour stdTime stdTm baseHour hour stdDt stdDate sumStdHour stdHh tmZon
```

> **Claude**
> 여기서 멈추겠습니다. 필수 파라미터가 **"집계시간단위구분코드 + 기준시"**
> 라는 것은 이 API 가 **시간 단위 실시간 조회용**이라는 뜻입니다.
> 우리에게 필요한 건 2016~2025 연도별입니다.
> **파라미터 이름을 맞혀도 그건 안 줍니다. 답이 나와도 쓸모가 없는
> 추적이라 중단합니다.**

## 그날 배운 것

1. **검증하면 반드시 성공하는 가설은 검증할 가치가 없다.**
   먼저 할 일은 자료 수집이 아니라 "이 결과가 틀렸다면 어떻게
   드러날까" 를 설계하는 것이었습니다 — 그것이 위약 밴드입니다.

2. **분석기를 먼저 검증한다.** 답을 심어 놓고 되찾게 하면, 나중에
   이상한 결과가 나왔을 때 "코드가 고장났나" 를 후보에서 지울 수 있습니다.

3. **답이 나와도 쓸모없는 추적은 중단한다.** 파라미터 이름 맞히기는
   재미있지만 그 API 는 애초에 우리가 원하는 것을 안 갖고 있었습니다.
