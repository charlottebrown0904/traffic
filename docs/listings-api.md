# 매물 API

중개사가 등록한 매물을 **서버에 저장**하고 여러 사람이 함께 봅니다.
(이전에는 브라우저 localStorage 에만 남아 본인만 볼 수 있었습니다.)

```bash
make serve        # 화면 + API 를 같은 포트로 (http://127.0.0.1:8000)
make test-server  # 인증·권한 13개 항목 검증
```

## 저장소를 분리한 이유

```
DuckDB   (data/processed/redt.duckdb)    분석 — 대량 집계
SQLite   (data/processed/listings.sqlite) 운영 — 매물·중개사·세션
```

DuckDB 는 컬럼 지향이라 수백만 행 집계에 강하지만, 짧은 쓰기가 잦은 운영 데이터에는
맞지 않습니다. 매물은 전형적인 OLTP 라 SQLite 를 씁니다.

## 엔드포인트

| 메서드 | 경로 | 인증 | 설명 |
|---|---|---|---|
| POST | `/api/brokers` | — | 중개사 가입 → 토큰 |
| POST | `/api/auth/login` | — | 로그인 → 토큰 |
| POST | `/api/auth/logout` | ✔ | 세션 삭제 |
| GET | `/api/me` | ✔ | 내 정보 |
| GET | `/api/listings` | 선택 | 목록 (`?mine=true`, `?kind=`, `?tollgate_id=`) |
| POST | `/api/listings` | ✔ | 등록 |
| PATCH | `/api/listings/{id}` | ✔ | 수정 (본인만) |
| DELETE | `/api/listings/{id}` | ✔ | 내리기 (본인만, 소프트 삭제) |
| POST | `/api/listings/{id}/publish` | ✔ | 게시 — **결제 자리** |
| GET | `/api/fees` | — | 수수료 정책 |

문서: 서버 실행 후 `/docs` (FastAPI 자동 생성)

## 매물 상태

```
등록 → pending_payment ──[결제]──> active ──[90일]──> expired
                                     │
                                  removed  (내리기)
```

**결제 전 매물은 공개 목록에 뜨지 않습니다.** 본인에게만 보입니다.
`내리기` 는 행을 지우지 않고 상태만 바꿉니다 — 광고 이력은 분쟁 대비로 남겨야 합니다.

## 제품이 이어지는 지점

좌표를 입력하면 서버가 **가장 가까운 영업소와 거리 밴드를 계산해 저장**합니다.

> 토지 · 매매 · 48,000만원
> 경기도 화성시 양감면 정문리 1-2
> **발안영업소 1.4km · 0-3km**

매물 카드에서 그 IC 를 누르면 지도로 이동해 해당 권역의 스코어를 볼 수 있습니다.
분석과 매물이 붙는 곳이 여기입니다.

## 법적 요건 반영

공인중개사법 제18조의2 (중개대상물의 표시·광고)

- 등록 주체를 **중개사 계정으로 제한** — 로그인 없이는 등록 불가
- 가입 시 **사무소 명칭 · 소재지 · 등록번호 · 대표 성명 · 연락처** 필수
- 매물 응답에 위 항목이 **항상 포함** (누락 시 테스트 실패)
- 매물에 **거래 형태(매매/임대)** 필수

## 검증 (`make test-server`)

되는지보다 **되면 안 되는 것이 막히는지**를 주로 봅니다.

| 검증 | |
|---|---|
| 응답에 이메일·비밀번호 해시 미노출 | ✔ |
| 중복 이메일 409 · 짧은 비밀번호 422 | ✔ |
| 로그인 8회 실패 후 429 잠금 | ✔ |
| 미인증·위조 토큰 등록 차단 | ✔ |
| **타 중개사의 조회·수정·삭제 모두 404** (존재 사실도 미노출) | ✔ |
| 결제 전 매물 공개 목록 미노출 | ✔ |
| 음수 가격 · 국내 범위 밖 좌표 422 | ✔ |
| 삭제는 소프트 삭제 | ✔ |
| 로그아웃 즉시 토큰 무효 | ✔ |

## 구현된 보안

- 비밀번호: `hashlib.scrypt` (N=2^14), 계정별 salt
- 토큰: `secrets.token_urlsafe(32)`, **DB 에는 SHA-256 해시만** 저장, 14일 만료
- 비밀번호 비교는 `hmac.compare_digest` (상수 시간)
- 로그인 실패 메시지 통일 — 계정 존재 여부를 알려주지 않음
- 모든 쿼리 파라미터 바인딩 (SQL 인젝션 차단)
- 사용자 입력 텍스트는 화면에서 escape 후 삽입

## 아직 남은 것 ⚠️

| 항목 | 현재 | 운영 전 필요 |
|---|---|---|
| **결제** | `publish` 가 결제 없이 게시 | PG 연동. 이 함수는 **결제 검증 성공 콜백에서만** 호출되어야 함 |
| **중개사 자격 검증** | 등록번호 형식만 검사 | 시군구 조회 연동. 현재 `status='pending'` 으로만 표시 |
| 토큰 보관 | 브라우저 localStorage | XSS 에 노출됨. httpOnly 쿠키 + CSRF 토큰이 안전 |
| 로그인 잠금 | 프로세스 메모리 | 다중 워커로 띄우면 Redis 등 공유 저장소 필요 |
| HTTPS | 없음 | 필수. 토큰이 평문으로 오감 |
| 이메일 인증 | 없음 | 가입 시 확인 메일 |
| 허위매물 신고 | 없음 | 공인중개사법상 모니터링 의무 |
| 만료 처리 | `paid_until` 저장만 | 만료 배치 또는 조회 시 판정 |

**결제와 자격 검증 두 가지는 실제 과금 전에 반드시 붙어야 합니다.**
지금 구조는 그 자리를 비워둔 것이지, 우회한 것이 아닙니다.
