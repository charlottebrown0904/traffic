# 법적·규제 체크리스트 (Step 6 이전에 반드시 검토)

> 아래는 조사 시 확인해야 할 항목 정리이며 법률 자문이 아닙니다.
> 서비스 출시 전 부동산·플랫폼 전문 변호사 검토를 권합니다.

## 1. 매물 등록 수수료 모델
- **공인중개사법 제18조의2 (중개대상물의 표시·광고)**
  중개대상물 광고는 **개업공인중개사만** 가능. 플랫폼은 광고 매체 지위.
  → 등록 주체를 반드시 개업공인중개사로 제한하고, 등록 시 **자격증·등록번호 검증** 필요.
  → 명시의무 항목(소재지, 면적, 가격, 중개사무소 명칭·연락처, 등록번호 등) 입력 강제.
- **허위매물**: 표시·광고 모니터링 의무 및 과태료. 신고/삭제 프로세스 설계 필요.
- 플랫폼이 직접 중개행위를 하면 무등록 중개가 됩니다. **"중개 아님"** 경계를 UI/약관에 명확히.

## 2. 실거래가 데이터 재사용
- 국토부 실거래가 공개시스템 / OpenAPI의 **이용약관·출처표시 의무** 확인
- 공공데이터법상 이용은 원칙적으로 자유이나, **가공물 상업적 제공** 시 출처표시 및
  제3자 권리 침해 금지 조항 준수
- 원본 데이터 **대량 재배포(벌크 다운로드 제공)**는 피하고, 가공 지표 형태로 제공 권장

## 3. 투자 예측 서비스
- 부동산은 자본시장법상 금융투자상품이 **아니므로** 투자자문업 등록 대상이 아닙니다.
- 다만 **「부동산개발업법」, 「표시광고법」(부당한 표시·광고)** 리스크 존재.
- 문구 원칙:
  - ❌ "이 지역은 오릅니다", "수익률 OO% 예상"
  - ⭕ "교통량 증가율 상위 10% 권역", "과거 5년 실거래 기준 통계"
  - 모든 화면에 **면책 고지**: 과거 데이터 기반 통계이며 미래 수익을 보장하지 않음
- 「유사수신행위법」에 걸리지 않도록 **원금·수익 보장 표현 절대 금지**

## 4. 개인정보
- 실거래가 자체는 개인정보가 아니지만 **지번 + 금액 + 시점** 결합은 특정 개인의 재산 정보로
  재식별 가능성 논란이 있습니다. 국토부 공개 수준을 넘는 정밀도로 가공하지 않기.
- 중개사·투자자 회원 정보는 개인정보보호법 일반 규정 적용.

## 5. 결제
- 등록 수수료 과금 → **전자상거래법** 청약철회·환불 규정, 통신판매업 신고 필요.
