# 첫 화면의 화면 캡쳐 여섯 장 (2026-09-12)

지시:

> '무엇을 보여주나'·'자료' 두 칸은 삭제(숨김)하고, 우리 서비스에서 사용자가
> 할 수 있는 것들을 넣읍시다. **실제 화면 캡쳐**로 나열해 주세요 —
> 시군구동별 용도지역별 실거래가와 추이, IC 차종별 통행량, 전국 실거래가
> 조회, 회원가입 시 현재 가치 예상. 우리 서비스가 할 수 있는 것과
> **우리만 할 수 있는 것**을 강조해 주세요.

## 만드는 법

```bash
node scripts/build_shots.js      # 찍는다 (pack_shots.py 를 이어서 부른다)
PYTHONPATH=src python3 scripts/test_web.py
```

손으로 찍지 않습니다. 화면이 바뀌면 첫 화면의 그림도 같이 낡는데, 손으로
찍으면 아무도 그것을 모릅니다. 스크립트로 두면 한 줄로 다시 찍고, **무엇을
찍었는지가 코드에 남습니다** — 어느 탭, 어느 필터, 어느 연도였는지.

| 파일 | 무엇 | 어떻게 |
|---|---|---|
| `map.webp` | 전국 — 시·도별 평당가 | **사람이 찍음** (배경 지도가 살아 있다) |
| `region.webp` | 읍·면·동·리 평당가 (이천 주변) | **사람이 찍음** |
| `cadastral.webp` | 지적편집도 — 필지 경계 + 동별 평당가 | **사람이 찍음** |
| `parcel.webp` | 필지 진단 여섯 축 (안성 보개면, **지번 모자이크**) | **사람이 찍음** |
| `trend.webp` | 화물 통행량 × 계획관리·생산관리 실거래가 (지수) | 추이 비교 탭, 계열 셋 |
| `rank.webp` | IC 차종별 통행량 순위 | 교통량 순위 탭, 화물·직전 해 |
| `value.webp` | 현재 가치 산출표 | 그 카드의 '현재 가치' (예시 필지) |

`scripts/pack_shots.py` 가 다듬습니다 — **자르기 · 줄이기(폭 1100) ·
WebP(품질 80)** 뿐입니다. 그림 안의 무엇도 고치지 않습니다. 여섯 장 합쳐
267KB 이고, `test_web.py` 가 500KB 를 넘지 않는지 봅니다.

## 진짜 화면입니다 — 가짜로 채운 것 셋

앱 코드도 `/app/data` 자료도 배포된 것과 같습니다. 이 상자에서 밖으로 나갈
길이 막혀 있어(egress 차단) 대신한 것만 셋입니다.

1. **Leaflet** — CDN 대신 npm 으로 받은 **같은 버전**(1.9.4).
2. **로그인** — Supabase 를 부를 수 없어 '승인된 회원' 으로 둡니다.
3. **필지 하나** — 브이월드를 부를 수 없어 `test_map.js` 와 같은 예시
   필지·표준지를 씁니다. 그 두 장(`parcel`·`value`)은 첫 화면에
   **'예시 자료로 띄운 화면입니다'** 라고 적습니다.

**못 찍는 것: 배경 지도.** 타일 서버(브이월드·OSM)로 나갈 수 없습니다.
그래서 지도는 스크립트로 찍으면 우리가 그리는 것(값 태그·영업소 점·조회
배지)만 보입니다.

→ **지도 석 장은 사람이 찍어 보낸 것을 씁니다** (2026-09-12). 배경 지도가
살아 있어 훨씬 낫습니다. `scripts/build_shots.js` 의 `HUMAN` 집합
(`map`·`region`·`cadastral`·`parcel`)에 그 이름이 있고, 같은 이름의 `.webp` 가
이미 있으면 **덮어쓰지 않고 건너뜁니다** — 로그에 '사람이 찍은 것을 그대로
둡니다' 라고 적습니다. 스크립트로 다시 찍고 싶으면 그 파일을 지우고
돌리면 됩니다.

### 실제 필지 화면의 지번은 가립니다

`parcel.webp` 는 **실제 필지** 화면입니다 (안성 보개면, 생산관리지역
2,241㎡). 남의 땅 지번을 첫 화면에 적어 두지 않으므로 **지번만 모자이크**
했습니다 — 소재지는 리까지 남겼습니다. 리 하나에 필지가 수천 개라 특정되지
않고, 어느 지역 화면인지는 보여야 합니다.

**화면에는 가렸다는 말을 적지 않습니다** (지시 2026-09-12). 모자이크는 보면
알고, 굳이 적으면 첫 화면이 변명하는 투가 됩니다. 그래서 그림 파일 자체가
가림의 유일한 자물쇠입니다 — `parcel.webp` 를 새로 만들 때 **반드시 다시
가려야 합니다.** 검사는 그림 속을 못 봅니다.

모자이크 자리는 글자 픽셀에서 읽었습니다 (주소 줄 y 42~64, 지번 x 166~210,
7배 축소 후 확대). 원본은 저장소에 없으니 다시 가릴 일은 없습니다.

`value.webp`(산출표)는 그대로 **예시 필지**라서 지번을 가리지 않았습니다.
없는 지번이고, 그림 아래에 '예시 자료로 띄운 화면입니다' 라고 적혀 있습니다.

사람이 찍은 원본은 저장소에 두지 않습니다. 다듬기는 폭 상한(전국은 제
크기 517px 그대로, 나머지 820px)과 WebP 품질뿐이고, 그림 안의 무엇도
고치지 않았습니다.

## 왜 캡쳐가 밝은 테마 한 벌인가

어두운 화면을 켠 사람에게도 밝은 캡쳐가 나갑니다. 두 벌을 넣으려면
`background-image` 로 갈아 끼워야 하는데, 그러면 `alt` 설명이 사라집니다
(화면을 못 보는 사람에게 이 칸이 통째로 없어집니다). 캡쳐에 테두리와 둥근
모서리가 있어 '스크린샷' 으로 읽히므로, 설명을 지키는 쪽을 골랐습니다.

## 같이 고친 것

- **'교통량 순위'·'추이 비교' 탭을 다시 세웠습니다.** 2026-09-10 에 접어
  두었던 넷 중 둘입니다. 첫 화면이 광고하는 화면이 정작 앱에 없으면
  거짓말이라서요. **스코어보드·가설 판정은 그대로 접어 둡니다** — 그쪽은
  우리 판단 근거입니다. `test_web.py` 가 '광고한 탭이 서 있는지' 를 봅니다.
- **'상위 0%' 를 '최상위' 로.** 백분위가 100 이면 `100 - pct` 가 0 이 되어
  필지 카드에 '상위 0%' 가 찍혔습니다. 뜻은 '또래 전부보다 낫다' 인데
  읽는 사람에게는 고장으로 보입니다. 캡쳐에 그대로 찍혀서 발견했습니다.
- **산출표 캡쳐는 앞쪽만** 싣습니다 (`pack_shots.py` 의 `value: 0.42`).
  뒤쪽(개별요인 격차율·그 밖의 요인·결정단가)은 회원 화면의 몫입니다.
  첫 화면에서는 아래를 부드럽게 덮고 무엇이 더 있는지 글로 적습니다 —
  그림을 고치는 것이 아니라 **덮는** 것입니다.
- 걷어낸 '자료' 칸의 출처는 **바닥글**로 내렸습니다. 공공데이터 이용
  조건이 출처표시를 요구합니다 (docs/legal-notes.md §6).

## '여기서만' 에 적은 것

경쟁 서비스를 이름으로 부르지 않습니다 — 비교 표시·광고는 표시광고법
심사 대상입니다 (docs/legal-notes.md §3). 대신 우리가 실제로 하는 일로
적었습니다.

1. 단지가 아니라 **용도지역과 필지** 단위.
2. 통행량을 **차종까지** (영업소 561곳 × 1~6종 × 2003년부터).
3. **값을 내는 방법을 숨기지 않는다** (다섯 마디를 화면에, 산식은 가이드에).
4. **모르는 것은 모른다고 적는다** (거래 5건 미만은 값 없이 건수만, 민자
   영업소는 통행량 없음, 미래 가치는 예측이 아니라 참고 지표).
