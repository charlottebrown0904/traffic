# 휴대폰만으로 수집 돌리기 (GitHub Actions)

PC 도, 터미널도, Codespace 도 필요 없습니다.
GitHub 웹페이지에서 **버튼 하나**를 누르면 클라우드에서 수집이 돌고,
결과가 저장소에 커밋되며, Vercel 이 자동으로 배포합니다.

---

## 준비 — 키를 Actions Secrets 에 넣기 (한 번만)

Codespaces 와 Actions 는 **비밀값 저장소가 서로 다릅니다.**
Codespaces 에 넣어두신 것과 별개로 Actions 쪽에도 등록해야 합니다.

**https://github.com/charlottebrown0904/traffic/settings/secrets/actions**

`New repository secret` 을 눌러 세 개를 등록합니다.

| Name | Value |
|---|---|
| `DATA_GO_KR_KEY` | 공공데이터포털 Decoding 인증키 |
| `VWORLD_KEY` | 브이월드 인증키 |
| `EX_API_KEY` | 한국도로공사 인증키 |

> 왼쪽 사이드바 `Secrets and variables` 아래에서 **`Actions`** 인지 확인하세요.
> `Codespaces` 화면과 생김새가 거의 같습니다.

---

## 실행 — 버튼 누르기

1. 저장소 상단 **`Actions`** 탭
2. 왼쪽 목록에서 **`수집 (실거래가 → 지오코딩 → 분석 → 화면)`**
3. 오른쪽 **`Run workflow`** 버튼
4. 입력칸 네 개가 뜹니다. **그대로 두셔도 됩니다.**

   | 항목 | 기본값 | 뜻 |
   |---|---|---|
   | 수집 시작 | `2016-01` | 이 달부터 |
   | 수집 끝 | `2025-12` | 이 달까지 |
   | 물건 종류 | `land,factory` | 토지, 공장·창고 |
   | 지오코딩 최대 | `4000` | 이번 실행에서 좌표로 바꿀 건수 |

5. 초록 **`Run workflow`** 를 한 번 더 누릅니다.

노란 점이 생기면 실행 중입니다. 눌러서 들어가면 어느 단계까지 갔는지 보입니다.

---

## 걸리는 시간

| 단계 | 예상 |
|---|---|
| 패키지 설치 | 1~2분 |
| 점검 | 1분 |
| 영업소 마스터 | 1분 |
| 실거래가 수집 | **15~30분** |
| 지오코딩 | 4,000건 기준 10~20분 |
| 공간 조인·분석·화면 | 2~3분 |

전체 **30분~1시간**. 휴대폰을 꺼두셔도 클라우드에서 계속 돕니다.

---

## 여러 번 나눠 돌리기

지오코딩은 브이월드 일일 한도가 있어 한 번에 다 못 할 수 있습니다.
**그냥 다음 날 `Run workflow` 를 또 누르시면 됩니다.**

이미 받은 것은 건너뛰고 남은 것부터 이어갑니다. 실거래가도 마찬가지입니다
(시군구×년월 단위로 기록해둡니다).

Vercel 이 그 커밋을 받아 1분 안에 배포합니다.

**https://sado-toji.vercel.app/app**

## 실패했을 때

빨간 X 가 뜨면 눌러서 들어가, **빨간색으로 표시된 단계**를 펼쳐 봅니다.
그 화면을 캡처해서 보내주세요. 키는 GitHub 이 자동으로 `***` 로 가립니다.

가장 흔한 원인:

| 증상 | 원인 |
|---|---|
| `점검` 단계에서 실패 | Actions Secrets 에 키가 없거나 오타 |
| `실거래가 수집` 실패 | 데이터셋 활용신청 누락, 또는 일일 한도 초과 |
| `지오코딩` 실패 | 브이월드 일일 한도 — 다음 날 다시 실행 |

## Codespaces 와 무엇이 다른가

| | Actions | Codespaces |
|---|---|---|
| 필요한 것 | 브라우저 (휴대폰 가능) | 브라우저 + 터미널 조작 |
| 조작 | 버튼 클릭 | 명령어 입력 |
| 중간 확인 | 단계별 로그 | 자유롭게 탐색 |
| 적합한 때 | **정해진 작업 반복** | 새로 만들거나 고칠 때 |

수집처럼 정해진 일은 Actions 가 낫습니다.
