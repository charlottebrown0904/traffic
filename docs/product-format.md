# 제품 형식 (web/)

API 키와 실데이터를 기다리는 동안, **데이터 뒤쪽 전부를 먼저 완성**했습니다.
합성 데이터로 끝까지 돌아가므로 실데이터가 들어오면 같은 명령이 그대로 실행됩니다.

```bash
make web     # score → export-web → 로컬 서버 (http://localhost:8000)
```

## 화면이 DB 를 모른다

```
DuckDB ──[export-web]──> web/data/*.json ──> 화면
```

화면은 JSON 4개만 읽습니다. 합성이든 실데이터든 **화면 코드는 한 줄도 바뀌지 않습니다.**
`meta.is_synthetic` 이 참이면 상단에 데모 배너가 뜨고, 실데이터로 바꾸면 자동으로 사라집니다.

## 탭 3개

### 탐색 — 투자자용 지도
영업소 마커를 분면 색으로 칠하고, 선택하면 거리 밴드(0-3 / 3-5 / 5-10 / 10-20km) 반경과
반경 내 실거래 점을 함께 보여줍니다. 우측 패널에 연도별 가격·교통량 추이.

필터: 분면 / 물건종류 / 연도 / **지번단위 좌표만** ← 지번 마스킹 대응 ([api-keys.md](api-keys.md) 참고)

### 스코어보드 — 2×2 매트릭스

```
              가격 모멘텀 ↑
    과열 주의     │    동반 상승
   ───────────────┼───────────────  교통량 모멘텀 →
      관망        │   저평가 후보    ← 찾는 것
```

**저평가 후보** = 통행량은 늘었는데 가격은 아직 따라오지 않은 구간.
투자자가 이 화면을 보러 옵니다.

신뢰도(높음/보통/낮음)를 함께 표시합니다. 거래 표본이 얇은 영업소의 스코어를
그대로 믿게 두면 안 되기 때문입니다.

### 매물 — 중개사용
등록 폼 + 목록. **개업공인중개사만 등록 가능**하다는 안내와 등록번호 입력을 강제합니다
(공인중개사법 제18조의2). 현재는 형식 확인용으로 브라우저에만 저장됩니다.

## 문구 원칙

모든 화면 하단에 면책 고지가 상시 노출됩니다.

> 과거 실거래 신고 자료와 교통량 통계를 요약한 **스크리닝 지표**입니다.
> 미래 가격을 예측하거나 보장하지 않으며, 투자 판단의 책임은 이용자에게 있습니다.

"예측" 대신 "스크리닝", "오릅니다" 대신 "상위 N%". 근거는 [legal-notes.md](legal-notes.md).

## 아직 비어 있는 것

| 항목 | 현재 | 필요한 것 |
|---|---|---|
| 지도 타일 | OpenStreetMap 공개 타일 | 상용 시 별도 계약 |
| 매물 저장 | 브라우저 localStorage | 서버 + DB |
| 결제 | 금액 표시만 | PG 연동, 통신판매업 신고 |
| 중개사 검증 | 등록번호 형식 검사만 | 실제 자격 조회 연동 |
| 로그인 | 없음 | 계정·권한 |

지도 라이브러리를 못 불러오는 환경(오프라인·방화벽)에서도
**스코어보드와 매물 탭은 정상 동작**하도록 만들어두었습니다.
