# API 키 신청 가이드 — 어디서 무엇을 신청하는가

필요한 키는 **3개**이고, 그중 공공데이터포털 키 하나로 데이터셋 7종을 엽니다.
체크리스트는 `internal/PROGRESS.md` 의 **발급이 필요한 API 키** 표에서 관리합니다.

| # | 키 | 포털 | 없으면 | 소요 |
|---|---|---|---|---|
| 1 | `DATA_GO_KR_KEY` | 공공데이터포털 | 실거래가를 못 받음 (필수) | 즉시~2시간 |
| 2 | `VWORLD_KEY` | 브이월드 | 좌표가 없어 지도·거리분석 불가 (필수) | 즉시~1일 |
| 3 | `EX_API_KEY` | 고속도로 공공데이터포털 | 영업소 좌표를 못 받음 (대체 가능) | 즉시 |

## ⛔ 공개 전환 전에 반드시 — `DATA_GO_KR_KEY` 재발급

저장소 이력에 **살아 있는 키가 하나** 있습니다.

```
커밋   25292d8  "Update .env.example"
파일   config/.env.example
칸     DATA_GO_KR_KEY  (디코딩 키가 값까지 채워진 채로)
```

> 값은 여기 옮겨 적지 않습니다. 문서에 적으면 그 문서가 또 하나의
> 유출처가 됩니다. 확인하시려면 `git show 25292d8` 를 보세요.

지금 파일에서는 지웠지만 **커밋에는 영구히 남습니다.** git 이력은
지운 내용도 보관하는 것이 존재 이유이기 때문입니다.

저장소를 public 으로 바꾸면 그 순간 이 키가 공개됩니다. 그리고
**한 번 공개된 커밋은 되돌릴 수 없습니다** — 남이 복제해 가면 다시
private 으로 바꿔도 그 복제본은 사라지지 않습니다.

### 순서 (바꾸면 안 됩니다)

1. 공공데이터포털에서 **디코딩 키 재발급** (마이페이지 → 개발계정 →
   해당 활용신청 → 인증키 재발급). 재발급하는 순간 옛 키는 죽습니다.
2. 새 키를 **GitHub Secrets** 와 **Vercel 환경변수**에 넣습니다
   (아래 「새 키를 넣는 곳」).
3. 넣은 것이 동작하는지 확인합니다.
4. 그 다음에 저장소를 public 으로 바꿉니다.

3번까지 끝나기 전에 4번을 하면, 살아 있는 키가 공개된 채로 남습니다.

### 새 키를 넣는 곳 — **Vercel 한 곳뿐입니다**

| 넣는 곳 | 이름 | 쓰는 쪽 |
|---|---|---|
| Vercel → 프로젝트 → **Settings → Environment Variables** | `DATA_GO_KR_KEY` | 중계기 `api/relay.js` |

GitHub Secrets 에는 **넣지 않습니다.** 러너(미국)는 한국 공공 API 에
직접 못 붙어서 서울 중계기를 거치는데, 키를 끼워 넣는 것은 그 중계기가
합니다(`api/relay.js` 의 `ALLOW`). 러너는 키 없이 중계기 주소와 토큰만
갖고 돕니다 — 수집 워크플로의 `env` 에 `DATA_GO_KR_KEY` 가 없는 것이
그 증거입니다.

키를 안 쓰는 곳에 넣어 두면 지켜야 할 자리만 하나 늘어납니다.

**넣는 순서 (휴대폰에서 가능합니다)**

1. Vercel → 프로젝트 `sado-toji` → **Settings → Environment Variables**
2. 기존 `DATA_GO_KR_KEY` 를 **Edit** 해서 새 값으로 바꿉니다
   (없으면 Add New. Name 은 정확히 `DATA_GO_KR_KEY`)
3. 적용 대상은 **Production·Preview·Development 모두** 체크
4. Save
5. **Deployments → 맨 위 것 → ⋯ → Redeploy** — 환경변수는 재배포해야
   반영됩니다. 이걸 빠뜨리면 옛 키로 계속 돕니다.

**확인**

수집 워크플로를 `stage=analyze` 로 한 번 돌리면 `doctor` 단계가
실거래가 API 를 실제로 불러봅니다. 거기서 통과하면 새 키가 살아 있는
것입니다.

### 절대 하지 마세요

- 키를 채팅창에 붙여넣기 — 대화 기록에 남습니다
- `config/.env.example` 에 값 쓰기 — 이번 사고가 정확히 그것이었습니다
- 커밋해서 나중에 지우기 — 지워도 이력에 남습니다

`config/.env` 는 `.gitignore` 에 있어 커밋되지 않습니다. 로컬에서
쓰실 때는 거기에 넣으세요.

## 1. 공공데이터포털 — 실거래가 (가장 중요)

**포털**: https://www.data.go.kr → 회원가입(무료)

### 신청할 데이터셋 4개

각 페이지에서 **`활용신청`** 버튼을 누릅니다. 자동승인이라 별도 심사가 없습니다.

| 우선순위 | 데이터셋 | 링크 | 이 프로젝트에서 |
|---|---|---|---|
| ★★★ | 국토교통부_**토지** 매매 실거래가 자료 | [15126466](https://www.data.go.kr/data/15126466/openapi.do) | 핵심 |
| ★★★ | 국토교통부_**공장 및 창고 등** 부동산 매매 실거래가 자료 | [15126470](https://www.data.go.kr/data/15126470/openapi.do) | 핵심 |
| ★★ | 국토교통부_**단독/다가구** 매매 실거래가 자료 | [15126465](https://www.data.go.kr/data/15126465/openapi.do) | 보조 |
| ★ | 국토교통부_**상업업무용** 부동산 매매 실거래가 자료 | [15126463](https://www.data.go.kr/data/15126463/openapi.do) | 선택 |
| ★★ | 한국부동산원_**부동산통계 조회 서비스** (지가변동률) | [15134761](https://www.data.go.kr/data/15134761/openapi.do) | 거시 통제변수 |

> 데이터셋마다 따로 활용신청해야 하지만 **인증키는 계정당 하나로 공용**입니다.
> 신청 후 `마이페이지 → 데이터활용 → 인증키 발급현황` 에서 확인합니다.

### ⚠️ 함정 1 — Encoding 키가 아니라 **Decoding 키**를 쓰세요

인증키가 두 가지 형태로 표시됩니다.

```
일반 인증키(Encoding)  →  abc%2Bdef%2F123%3D...     ← ❌ 쓰지 마세요
일반 인증키(Decoding)  →  abc+def/123=...           ← ⭕ 이걸 .env 에 넣으세요
```

Python `requests` 는 파라미터를 자동으로 URL 인코딩합니다. Encoding 키를 넣으면
**이중 인코딩**이 되어 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` 가 납니다.
이 프로젝트 코드는 `requests` 의 `params=` 로 넘기므로 **Decoding 키**가 맞습니다.

### ⚠️ 함정 2 — 신청 직후 바로 안 될 수 있습니다

승인은 즉시 뜨지만 실제 호출 가능까지 **1~2시간** 걸리는 경우가 있습니다.
바로 오류가 나면 한두 시간 뒤 다시 시도하세요.

### ⚠️ 함정 3 — 일일 트래픽

개발계정은 보통 **일 10,000 건** 제한입니다 (신청 화면에 표시됨).

| 범위 | 요청 수 | 소요 |
|---|---|---|
| 파일럿 (경기남부 8개 시군구 × 11년 × 2종) | 약 **2,100** | 하루 안에 완료 |
| 전국 (250개 시군구 × 11년 × 2종) | 약 **66,000** | 7일 또는 운영계정 전환 |

파일럿부터 시작하기로 한 이유가 여기에도 있습니다. 한도가 부족하면
`마이페이지 → 활용신청 상세 → 운영계정 전환` 으로 증량 신청할 수 있습니다.

## 2. 브이월드 (VWorld) — 지오코딩

**포털**: https://www.vworld.kr → 회원가입 → `오픈API` → **인증키 발급 신청**

- 신청서의 `활용API` 는 **데이터셋별이 아니라 API 종류별** 체크박스 14개입니다.
  '개별공시지가' 라는 항목은 없습니다. **전부 체크하세요** — 추가 심사도 비용도 없고,
  빠뜨린 것을 나중에 발견하면 재신청에 또 1~2일이 걸립니다.

  그중 반드시 들어가야 하는 것:

  | 체크 항목 | 쓰임 |
  |---|---|
  | **지오코더 API** | 지번 → 좌표 |
  | **2D데이터 API** | 개별공시지가 속성조회 (XML/JSON) |
  | **WMS/WFS API** | 개별공시지가 도형·속성 |
  | **국가중점 API** | 개별공시지가가 속한 국가공간 개방데이터 |

  개별공시지가는 공공데이터포털이 아니라 **브이월드가 제공**합니다
  (data.go.kr 의 표준데이터 15029071 도 브이월드로 연결됩니다).
  네 가지 중 어느 카테고리로 발급되는지는 확인하지 못했습니다 — 그래서 전부 체크합니다.
- 이메일 인증 메일이 오고, `인증키 관리` 에서 상태가 **승인**으로 바뀌면 사용 가능합니다.
- 레퍼런스: [Geocoder API 2.0](https://www.vworld.kr/dev/v4dv_geocoderguide2_s001.do)

### ⚠️ 함정 — 도메인 등록

VWorld 는 키 발급 시 **사용할 도메인을 등록**하게 합니다.
로컬/서버 스크립트에서 호출할 거라면 `localhost` 를 등록해두세요.
도메인이 안 맞으면 인증 오류가 납니다.

### 왜 필요한가

**실거래가 API 응답에는 좌표가 없습니다.** `시군구 + 법정동 + 지번` 문자열만 옵니다.
IC로부터의 거리를 재려면 이걸 좌표로 바꿔야 하고, 그게 이 키의 유일한 용도입니다.

## 3. 고속도로 공공데이터포털 — 영업소 좌표

교통량은 이미 확보하셨으니, 여기서 필요한 건 **영업소 위치(경위도)** 입니다.
두 가지 경로가 있고 **어느 쪽이든 됩니다.**

### ⚠️ 경로 A 는 안 됩니다

[15076728](https://www.data.go.kr/data/15076728/openapi.do) 은 공공데이터포털에 **목록만** 올라와 있고,
실제 발급과 호출은 한국도로공사 포털의 키를 씁니다. `DATA_GO_KR_KEY` 로는 호출되지 않습니다.
개별공시지가(15029071 → 브이월드)와 같은 경우입니다.

### 경로 B — 도로공사 자체 포털

- 인증키 발급: https://data.ex.co.kr/openapi/apikey/requestKey
- API 목록: https://data.ex.co.kr/openapi/intro/introduce02
- 교통량을 받으실 때 이미 발급받으셨다면 **그 키를 그대로** `EX_API_KEY` 에 넣으세요.

### 경로 C — 파일로 넣기

영업소가 수백 개 수준이라 CSV로 직접 넣어도 됩니다.
`data/raw/tollgate.csv` 에 `unitCode, unitName, xValue, yValue` 컬럼으로 저장 후:

```bash
python -m redt.cli tollgates --path data/raw/tollgate.csv
```

## 📌 반드시 알아두실 제약 — 토지 지번이 가려집니다

국토부는 개인정보 보호를 이유로 **토지와 일반건축물의 지번을 일부만 공개**합니다
(아파트·연립다세대는 지번까지 전부 공개).

즉 우리가 다루는 **토지·공장 거래 상당수는 정확한 지번을 알 수 없고**,
지오코딩이 **법정동 중심점**으로 떨어집니다. 오차는 대략 **±1~2km**.

이게 왜 문제냐면 — **0-3km 밴드를 그런 좌표로 만들면 밴드 자체가 무의미**해집니다.

**대응 (코드에 이미 반영)**
- `geocode_level` 컬럼에 `parcel`(지번단위) / `umd`(법정동단위)를 기록
- `settings.yaml` 의 `require_parcel_bands: ["0-3", "3-5"]` — 근거리 밴드는
  지번단위 좌표를 가진 거래만 사용
- 원거리 밴드(5-10, 10-20km)는 오차 ±1~2km가 상대적으로 작아 그대로 사용

수집 후 `python -m redt.cli geocode` 가 정밀도 분포를 출력합니다.
**지번단위 비율이 너무 낮으면**(예: 30% 미만) 근거리 밴드 표본이 부족해질 수 있고,
그때는 밴드를 `0-5 / 5-10 / 10-20 / 20-40` 으로 넓히는 쪽으로 조정합니다.

## KOSIS 오픈API (가설3 — 시군구 인구·사업체)

시군구 인구와 사업체·종사자는 KOSIS 에서 받습니다. **키가 하나 더
필요합니다.**

### 1. 키 발급

`kosis.kr` → 오픈API → 활용신청. 통계목록·통계자료 두 서비스를 함께
신청하시면 됩니다. 발급은 대개 즉시입니다.

### 2. 키를 넣을 곳 — Vercel 뿐입니다

**받은 키를 채팅에 붙여넣지 마세요.** 다른 키들과 같은 자리에 넣습니다.

    Vercel → 프로젝트 sado-toji → Settings → Environment Variables
    이름:  KOSIS_KEY
    값:    발급받은 키
    적용:  Production (다른 환경도 켜두면 편합니다)

넣은 뒤 **재배포**해야 반영됩니다 (Deployments → 최신 항목 → Redeploy).

키는 중계기(`api/relay.js`)에만 있고, GitHub Actions 러너에는 없습니다.
러너는 중계기 주소와 토큰만 압니다.

### 3. 왜 중계기가 키를 붙이나

`kosis.kr` 은 예전에 `{}` 로 열려 있었습니다 — 통과는 시키지만 키는 안
붙이는 상태입니다. 그러면 호출하는 쪽이 키를 들고 있어야 하는데, 그건
'키는 중계기에만 둔다' 는 원칙과 어긋납니다. 이제 `apiKey` 를 중계기가
채웁니다.

`KOSIS_KEY` 가 없으면 중계기가 이렇게 답합니다.

    {"relayError": "KOSIS_KEY 이 설정되지 않았습니다"}

'키가 없다' 와 '자료가 없다' 를 헷갈릴 일이 없도록 500 으로 분명히
말합니다.

## 부동산통계정보(R-ONE) `REB_KEY` — 지가변동률 (2026-09-12 추가)

시점수정의 원천입니다. 신청은 끝나 있고(`www.reb.or.kr/r-one/portal/openapi`),
남은 것은 **키를 Vercel 에 넣는 일 한 가지**입니다.

    Vercel → 이 프로젝트 → Settings → Environment Variables
    이름:  REB_KEY
    값:    R-ONE 에서 발급받은 인증키
    적용:  Production

넣은 뒤 **재배포**해야 반영됩니다. 다른 키와 마찬가지로 **채팅에 붙여넣지
마십시오.**

**다만 이 키는 GitHub Secrets 가 나을 수 있습니다.** 러너가
`www.reb.or.kr` 에 직접 닿으면 중계기를 안 거치므로 Vercel 함수 호출과
Fast Origin Transfer 가 0 이 됩니다. 닿는지는 재 봐야 압니다 —
Actions → **지가변동률 수집** → `mode: reach`(키 없이 됩니다). 계산과
판정 기준은 `docs/reb-openapi.md` §5 에 있습니다.

코드는 양쪽을 다 받습니다. `REB_KEY` 가 프로세스에 있으면 직접 부르고,
없으면 중계기가 끼웁니다 — **둘 중 한 곳에만** 넣으십시오.

파라미터 이름이 대문자 `Key` 인 것이 이 API 의 특징입니다. 소문자 `key`
(브이월드·도로공사)와 다른 항목이라 양쪽을 다 지우고 다시 넣습니다
(`api/relay.js` 의 `STRIP`, `src/redt/collect/http.py` 의 `_KEY_PARAMS`).

`www.reb.or.kr` 은 **키 없는 공개 화면 읽기에도** 쓰이므로(비준표 탐침),
이 호스트만 `optional: true` 입니다. `REB_KEY` 가 없으면 500 으로 막지
않고 키 없이 통과시킵니다 — 화면 탐침이 키를 기다리지 않게 하려는 것입니다.

쓸 수 있는 통계표와 호출 모양은 `docs/reb-openapi.md` 에 있습니다.
