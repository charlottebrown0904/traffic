# 측정 결과 — 해외 서버에서는 한국 공공 API 에 접속할 수 없다

2026-08-31, GitHub Actions 러너(미국 애리조나 피닉스, Azure)에서 측정.

## 결과

| 대상 | DNS | TCP 연결 | 응답 | 판정 |
|---|---|---|---|---|
| `apis.data.go.kr` | 성공 (27.101.236.63) | **30초·60초 타임아웃** | 없음 | **차단** |
| `www.data.go.kr` | 성공 | **30초 타임아웃** | 없음 | **차단** |
| `api.vworld.kr` | 성공 (211.188.33.95) | 0.47초 | **502** (루트 경로도 동일) | **거부** |
| `data.ex.co.kr` | 성공 (180.148.181.60) | 0.41초 | **400** (모든 경로 동일) | **거부** |

## 해석

- **data.go.kr** — DNS 는 풀리는데 TCP 3-way handshake 자체가 완료되지 않는다.
  방화벽에서 조용히 버리는(drop) 전형적인 모습이다.
- **브이월드 / 도로공사** — 연결·TLS 는 정상인데 게이트웨이가 즉시 502 / 400 을 돌려준다.
  **루트 URL 과 모든 후보 경로에서 같은 코드**가 나오므로 요청이 잘못된 것이 아니다.
  즉 앞서 collect 실행에서 본 404 는 "엔드포인트 경로 오류"가 아니었다.

세 곳 모두 **키와 무관하다.** 같은 실행에서 세 키 모두 정상 인식되었고
(64자 / 36자 / 10자), 인증 오류 메시지는 한 번도 오지 않았다.

## 결론

**수집은 한국 IP 에서 실행해야 한다.** GitHub Actions 러너(미국)로는 불가능하다.

Codespaces 도 미국·유럽·싱가포르 리전이라 같은 벽에 부딪힐 가능성이 높다.
(측정하지 않았으므로 단정하지 않는다 — 시도해 볼 가치는 있다.)

## 남은 선택지

| 방법 | 한국 IP | 필요한 것 |
|---|---|---|
| 국내 PC 에서 직접 실행 | ⭕ | 파이썬 설치 (1회) |
| 국내 PC 에 self-hosted 러너 설치 | ⭕ | 1회 설치 후 버튼으로 원격 실행 가능 |
| Vercel 서울 리전(icn1) 함수를 중계로 | ⭕ | 중계 함수 개발 |
| 한국 클라우드 VPS | ⭕ | 월 비용 |

`.github/workflows/collect.yml` 은 이 제약이 풀리기 전까지 실거래가 수집에 쓸 수 없다.
