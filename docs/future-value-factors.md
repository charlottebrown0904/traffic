# 미래 가치 인자 대장 — 무엇이 있고, 무엇이 검증됐나 (2026-09-14)

지시: 모멘텀은 미래 가치 인자 중 좋은 하나다. 나머지 인자를 다 적고 검증
현황을 보고하라. 그리고 그 인자들을 **모두 담아 보일 화면**을 제안하라.

이 문서는 대장이다. 설계는 `docs/future-value.md`(세 층), 후보 57개는
`docs/future-value-indicators.md`, 모멘텀은 `docs/future-value-momentum.md`,
화면 시안은 아티팩트 「미래 가치 인자판」 에 있다.

## 0. 상태 기호 — 다섯 단계

| 기호 | 뜻 | 화면에서 |
|---|---|---|
| ● **채택** | 실측 계수가 0 을 품지 않고 뒤로 돌린 검산을 통과 | 값을 움직인다 |
| ◐ **관계 있음** | 상관은 유의하나 인과가 아님 (수준 비교) | 값을 움직이지 않는다. '참고' 표시 |
| ？ **아직 모름** | 실측했으나 95% 구간이 0 을 품음 | 값을 움직이지 않는다. 구간을 보인다 |
| ○ **검증 전** | 자료는 있는데 실측을 안 함 | '관찰' 회색 칩 |
| ✕ **자료 없음** | 원천을 못 받았거나 없음 | 카드에 없음. 대장에만 |

**오늘 기준 ● 채택은 하나도 없다.** 이것이 보고의 첫 줄이다. 화면은 이
사실을 숨기지 않고, 채택되는 순서대로 값이 움직이게 짓는다.

## 6. 화면 제안 — 요약 (시안은 아티팩트 「미래 가치 인자판」)

물음이 셋이었다: 스파이더 차트인가, 항목별 ± 차트인가, 최소~최대 가격
범위인가. 답은 **셋을 층으로 쌓는다** 이고, 스파이더는 값에는 쓰지 않는다.

| 층 | 형태 | 답하는 물음 | 왜 이 형태 |
|---|---|---|---|
| **머리** | **가격 범위 띠** — 현재 가치 위에 최소·중앙·최대, 시나리오 셋 | "얼마가 되나" | 값 하나는 틀린다(현재 가치 ±30% 적중 28%). 범위와 시나리오가 정직한 답 |
| **몸** | **다리(폭포)** — 현재 → 시장 → 사건 → 필지 → 미래 | "무엇이 얼마나 옮기나" | 세 층이 곱셈이라 기여가 순서대로 쌓인다. 채택된 인자만 계단을 만든다 |
| **발** | **항목별 ± 막대 + 구간** — 인자마다 부호·크기·95% 구간·상태 기호 | "어느 인자가 확실하고 어느 것이 모르는가" | 0 을 품는 구간을 그대로 보이면 '아직 모름' 이 눈에 보인다 |
| 곁 | **상태 격자** — 인자 타일에 ●◐？○✕ | "무엇이 있고 무엇이 없나" | 오늘은 이것이 가장 정직한 화면이다 |
| (선택) | **레이더** — 자료 충족도만 | "이 땅에 몇 개 인자가 채워졌나" | 값 레이더는 안 쓴다 (§6-1) |

### 6-1. 스파이더(레이더)를 값에 쓰지 않는 까닭

- 음(−)을 못 담는다. 주변 공급·규제 신설·인구 감소·과열 경고는 음이다.
- 면적이 착시를 만든다. 축 순서를 바꾸면 같은 값이 다른 넓이가 된다.
- 미검증 인자를 검증된 것과 같은 크기로 그린다. 오늘은 그 비율이 3:27 이다.
- 불확실성(구간)을 얹을 자리가 없다.
현재 가치의 6축 레이더는 **상태**(도로·모양·지세 …)를 그리는 것이라 맞고,
미래 가치는 **변화의 부호와 크기**라 다르다. 굳이 쓰면 '자료 충족도' 하나다.

### 6-2. 모멘텀 상세

모멘텀 항목을 누르면 앞서 만든 「미래 가치 국면판」(2×2 국면 · 세 눈금 ·
3년 추세선 · 날씨 한 줄) 이 그 자리에 펼쳐진다. 인자판의 한 줄이 국면판의
머리 문장이 된다.
