앞서 giscus(깃허브 댓글)를 후보로 뒀었는데 **빼겠습니다.**

어차피 회원 기능(관심매물 저장·중개사 매물등록)을 만들 것이므로,
**같은 회원 시스템 위에 게시판을 올립니다.** 서비스 하나, 로그인 하나.

## 1. 가입해야 할 서비스

### ① Supabase — 회원·게시판·매물 데이터베이스  ★필수

https://supabase.com → `Start your project` → GitHub 계정으로 가입

프로젝트를 만들 때:

| 항목 | 값 |
|---|---|
| Name | `sado-toji` |
| Database Password | **길게 자동생성.** 화면에 나오면 안전한 곳에 보관 |
| Region | **`Northeast Asia (Seoul)`** ← 반드시 서울 |
| Plan | Free |

> Region 을 서울이 아닌 곳으로 잡으면 접속이 느려지고, 나중에 옮기려면
> 데이터를 통째로 이전해야 합니다. 지금 한 번만 제대로 고르면 됩니다.

무료 한도: 데이터베이스 500MB, 저장소 1GB, 월 활성사용자 5만 명.
초기에는 충분합니다.

**만든 뒤 저에게 알려주실 값 2개** (둘 다 공개돼도 되는 값입니다):

- `Project URL` — `https://xxxxx.supabase.co`
- `anon public` 키

**절대 알려주시면 안 되는 값**: `service_role` 키, 데이터베이스 비밀번호.
이 둘은 Vercel 환경변수에 대표님이 직접 넣습니다.

### ② 카카오 디벨로퍼스 — 카카오 로그인  ★필수

https://developers.kakao.com → 카카오계정으로 로그인 → `내 애플리케이션` → `애플리케이션 추가하기`

- 앱 이름: `사도될까`
- 사업자명: 개인이면 본인 이름

만든 뒤 `앱 설정 → 플랫폼 → Web` 에 사이트 도메인 등록:
```
https://sado-toji.vercel.app
```

`제품 설정 → 카카오 로그인` 을 **활성화 ON**, Redirect URI 는 제가 알려드린 뒤 넣으시면 됩니다.

> **이메일을 받으려면 '비즈니스 앱' 전환**이 필요하고, 사업자등록증이 있어야 합니다.
> 없으면 카카오 로그인은 되지만 이메일을 못 받습니다. 처음에는 그대로 가고,
> 사업자등록 후에 전환해도 됩니다.

**알려주실 값**: `REST API 키` (공개돼도 되는 값)

### ③ 이메일 발송 — Resend  ☆권장

가입 인증메일, 문의 알림에 씁니다.
Supabase 기본 발송은 **시간당 몇 건** 제한이라 실사용이 안 됩니다.

https://resend.com → 무료 가입 (월 3,000통)

도메인 인증이 필요합니다 → **④번 도메인이 먼저**입니다.
도메인이 없으면 이 단계는 미뤄도 됩니다. 초기 회원 수십 명까지는
Supabase 기본 발송으로 버팁니다.

### ④ 도메인  ☆권장

https://www.gabia.com 또는 https://www.hosting.kr

`sadotoji.com` / `sado-toji.kr` 같은 것. 연 1~2만원.

지금 당장은 아니어도 됩니다. 다만 **이메일 발송·신뢰도·브랜드** 셋 다
도메인에 걸려 있어서, 회원을 받기 시작하면 필요해집니다.

## 2. 준비해야 할 정보 (가입 아님)

약관과 개인정보처리방침에 **법적으로 들어가야 하는** 항목들입니다.
제가 초안을 쓰려면 이 값들이 필요합니다.

| 항목 | 설명 |
|---|---|
| 서비스명 | `사도될까` 로 확정할지 |
| 운영 주체 | 개인 or 사업자. 사업자면 상호·대표자·사업자등록번호·주소 |
| 연락처 | 문의받을 이메일 (개인 메일 말고 서비스용 권장) |
| 개인정보 보호책임자 | 이름·직위·연락처 (1인이면 대표님 본인) |

> **사업자등록이 지금 꼭 필요한가** — 무료 서비스라도 개인정보를 수집하면
> 개인정보보호법이 적용되고, 개인정보처리방침에 운영 주체를 밝혀야 합니다.
> 개인 명의로도 가능합니다. 다만 **중개사에게 돈을 받는 순간**부터는
> 사업자등록과 통신판매업 신고가 필요합니다 (P6).

## 3. 법적으로 확인이 필요한 것 — 중요

**공인중개사법 제18조의2**: 중개대상물을 광고할 때 중개사무소 정보
(명칭·소재지·연락처·등록번호)와 중개보조원 여부 등을 **반드시 표시**해야 합니다.

우리 서비스는 중개사가 매물을 올리는 구조이므로, **매물 등록 화면에서
이 정보를 필수 입력으로 받고 매물 상세에 노출**해야 합니다.
제가 그렇게 만들겠습니다.

**우리가 직접 중개를 하지는 않는다**는 점을 약관에 명시해야 합니다.
플랫폼은 게시 공간을 제공할 뿐이고, 거래는 중개사와 이용자 사이에서 일어납니다.

> 이 부분은 **개업공인중개사나 변호사에게 한 번 확인받으시길** 권합니다.
> 제가 쓰는 것은 초안이고, 법률 자문이 아닙니다.

## 4. 순서

지금 하실 것 — **①번 Supabase 하나면 충분합니다.**

```
① Supabase 프로젝트 생성 (서울 리전)      ← 지금
② 카카오 디벨로퍼스 앱 등록                ← 지금 (5분)
   ↓ 제가 스키마·회원·게시판을 만드는 동안
③ 2번의 정보 정리 (서비스명·운영주체·연락처)
④ 도메인 + Resend                          ← 회원 받기 직전
⑤ 사업자등록 + 통신판매업                  ← 유료화 직전 (P6)
```

①②를 마치고 **Project URL / anon 키 / 카카오 REST API 키** 세 개를
알려주시면 (전부 공개돼도 되는 값입니다), 제가 스키마부터 만들겠습니다.
