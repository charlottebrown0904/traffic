# 화면 한 벌 — 색 토큰 · 머리띠 · 문턱

2026-09-12 지시 "사이트 테마와 UI를 검토합시다" → "추천하신대로 모두 진행".

## 무엇이 문제였나

화면마다 제 팔레트를 갖고 있었습니다.

| 화면 | 바탕 | 강조색 | 다크모드 | 웹폰트 |
|---|---|---|---|---|
| `/` 랜딩 | `#FFFFFF` | `#C9A47C` | **없음** | 안 부름 (Pretendard 요청) |
| `/guide` | `#FAF7F3` | `#8A6547` | 있음 | 부름 |
| `/board` `/account` | `#FAF7F3` | `#8A6547` | 있음 | **안 부름** |
| `/app` 지도 | `#F6F7F9` | `#3F5B77` | 있음 | 부름 |

같은 제품의 네 쪽이 아니라 네 제품처럼 보였고, 지도앱 안에서는 **로고는
갈색인데 단추는 청회색**이었습니다. 어두운 화면을 켠 사람이 첫 쪽에서만
흰 바탕을 맞았습니다.

## 지금

### 1. 색 — `public/lib/theme.css` 한 곳

갈색 계열로 모았습니다. 로고·파비콘·랜딩이 이미 갈색이었고 청회색은 지도앱
한 곳이었습니다. 반대로 갔다면 로고부터 다시 그려야 합니다.

```
--ground --surface --surface-2      바탕 세 겹
--ink --muted --faint               글자 세 겹
--border --border-strong            선 두 겹
--accent --accent-soft --on-accent  강조
--brand-warm                        로고의 모래색. 점·띠 장식에만
--warn --block --ok --danger (+ -soft)
--shadow
```

어두운 값은 `--d-*` 로 **한 번만** 적습니다. `@media (prefers-color-scheme:dark)`
와 `:root[data-theme="dark"]` 는 그것을 옮겨 담기만 합니다. 예전에는 두 곳에
값을 따로 적어 두었다가 어긋나서, 지도앱의 거리 밴드가 한쪽에서는 보라·분홍·
청록인데 다른 쪽에서는 **다섯 개가 전부 회색**이었습니다.

**지도앱의 자료색은 옮기지 않았습니다.** 용도지역·거래 종류·교통량 구간·거리
밴드는 `public/app/style.css` 에 그대로 둡니다. 그 색들은 '서로 구별되는 것'이
임무라 브랜드와 같이 움직이면 안 됩니다.

### 2. 테마 단추 — `public/lib/theme.js`

자동 · 밝게 · 어둡게를 돌아가며 고릅니다. `localStorage['toji-theme']` 에
적고 `<html data-theme>` 를 세웁니다. `<head>` 에서 **defer 없이** 부릅니다 —
그림이 그려지기 전에 세워야 밝은 화면이 한 번 번쩍이지 않습니다.

붙일 자리는 `<span data-theme-switch></span>` 입니다. 화면에 여럿 있어도
됩니다 (누르면 전부 같이 바뀝니다).

### 3. 머리띠 — `.sitebar`

```html
<header class="sitebar">
  <div class="sitebar-inner">
    <a class="sitebar-brand" href="/">…</a>
    <span class="sitebar-crumb">…</span>        <!-- 있으면 -->
    <nav class="sitebar-nav">지도 · 가이드 · 게시판 · 내 계정</nav>
    <span data-theme-switch></span>
  </div>
</header>
```

지도앱은 제 머리띠(로고·탭·검색칸)가 있어 오른쪽 끝에 `.sitenav` 로 같은
길 안내를 답니다. **예전에는 지도에서 게시판·내 계정으로 갈 길이 화면에
없었습니다** — 가이드는 지도 위 안내문 안에만, 내 계정은 등급 잠금 문구
안에만 있었습니다.

`/account` 만 메뉴가 없습니다. 관문에 막혀 온 사람에게 돌아다닐 길을 주면
가입을 안 하고 돌아갑니다. 그것은 의도이고, 그 자리에는 테마 단추만 둡니다.

### 4. 화면 너비의 문턱 — 셋뿐

예전에는 `24rem · 34rem · 640px · 56rem · 760px · 60rem · 64rem` 일곱이 rem 과
px 섞여 있었습니다. 어느 화면에서 무엇이 바뀌는지 아무도 몰랐습니다.

| 문턱 | 뜻 | 무엇이 바뀌나 |
|---|---|---|
| `34rem` (544px) | 폰 | 두 칸·세 칸 판이 한 칸으로 |
| `56rem` (896px) | 태블릿 | 머리띠가 두 줄, 지도와 옆칸이 위아래로 |
| `64rem` (1024px) | 좁은 창 | 스코어보드·매물·추이 판이 한 칸으로 |

새 규칙을 더할 때도 이 셋 밖을 쓰지 않습니다.

## 같이 고친 것

- **랜딩에 다크모드가 생겼습니다.** 제 팔레트를 걷어내고 공통 토큰을 씁니다.
- **`/account` · `/board` 가 웹폰트를 안 부르고 있었습니다.** CSS 는 IBM Plex
  Sans KR 을 쓰라는데 두 쪽에만 `<link>` 가 없어 글자 모양이 달랐습니다.
- **랜딩이 Pretendard 를 쓴다고 적어 놓고 부르지 않았습니다.** 나머지와 같은
  IBM Plex Sans KR 로 맞췄습니다.
- **`theme-color` 가 전 쪽 `#C9A47C`** 였습니다. 이제 밝을 때 `#FAF7F3`,
  어두울 때 `#12100D` 로 머리띠와 같습니다. `site.webmanifest` 도 맞췄습니다.
- **관리자 회원 표가 눌려 있었습니다.** `.auth-card.wide` 에 64rem 을 줬는데
  부모 `.wrap` 이 52rem 이라 거기서 잘렸습니다. 칸부터 넓힙니다.
- **폰에서 검색칸이 42vw(164px) 였습니다.** 좁은 화면용 `width:100%` 가 파일
  앞쪽에 있어 뒤의 규칙에 눌렸습니다. 이제 한 줄 전체를 씁니다.
- **`gate.js` 가 글자색을 박아 쓰고 있었습니다**(`#3d3227`). 어두운 화면에서
  안 보였습니다. 토큰으로 바꿨습니다.

## 고칠 때 주의

- 색을 더할 자리는 `public/lib/theme.css` 입니다. 화면별 CSS 에 `--ground`
  같은 지면색을 다시 정의하지 마세요 — 그 순간 다시 갈라집니다.
- 어두운 값은 `--d-*` 에만 적습니다. 두 선택자는 옮겨 담기만 합니다.
- `scripts/test_web.py` 가 모든 쪽에 아이콘·manifest·`theme-color` 가 걸렸는지
  봅니다. `scripts/test_map.js` 가 지도앱 화면 전체를 봅니다 (약 5분).
