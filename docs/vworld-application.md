# 브이월드 인증키 신청서 — 입력값

https://www.vworld.kr → `오픈API` → `인증키 발급하기`

아래 내용을 그대로 붙여넣으시면 됩니다.

---

## 서비스명

```
사도될까 — 토지·공장 투자 스크리닝 서비스
```

## 서비스분류

드롭다운에서 **`부동산`** 을 선택합니다.
목록에 없으면 `국토·도시` 또는 `기타` 중 가까운 것을 고르세요.

## 서비스유형

**`웹사이트`** (기본 선택된 그대로)

## 서비스URL

```
https://sado-toji.vercel.app/
```

## 서비스설명

```
- 개요 : 고속도로 IC·영업소의 차종별 교통량 변화와 인근 토지·공장 실거래가의
  관계를 분석하여, 지도 위에서 지역별 가격 흐름을 보여주는 웹 서비스입니다.
  국토교통부 실거래가 공개시스템의 거래 자료와 한국도로공사의 영업소별 교통량을
  결합해 분석합니다. 실거래가 자료에는 좌표가 없고 주소 문자열만 제공되므로,
  브이월드 지오코더 API로 지번 주소를 좌표로 변환하여 IC로부터의 거리를 계산합니다.
  거래가 드문 필지의 기준 가격으로는 개별공시지가를 사용합니다.

- 서비스대상 : 토지·공장 매입을 검토하는 개인 투자자, 공인중개사.

- 목적 : 토지 가격 정보가 지역·물건별로 흩어져 있어 일반인이 비교하기 어렵다는
  문제를 해결하려 합니다. 교통량 변화라는 객관적 지표와 공공 실거래 자료를 연결해,
  특정 지역의 가격 흐름을 지도에서 한눈에 확인할 수 있게 하는 것이 목표입니다.
  비영리 연구 단계이며, 분석 결과는 투자 권유가 아닌 참고 정보로 제공합니다.
```

> 3000자 제한이고 위 내용은 약 400자입니다. 더 줄이셔도 됩니다.

## 활용API

**14개 전부 체크**합니다. 추가 심사나 비용이 없고, 빠뜨린 것을 나중에 발견하면
재신청에 또 1~2일이 걸립니다.

최소한 아래 넷은 반드시 포함되어야 합니다.

| 체크 항목 | 쓰임 |
|---|---|
| **지오코더 API** | 지번 → 좌표 |
| **2D데이터 API** | 개별공시지가 속성조회 (XML/JSON) |
| **WMS/WFS API** | 개별공시지가 도형·속성 |
| **국가중점 API** | 개별공시지가가 속한 국가공간 개방데이터 |

## 사용기관

**`민간`** 선택 후, 사업자등록증 상의 상호를 입력합니다.
개인이면 본인 이름을 넣어도 됩니다.

## 활용사례공개

**`공개동의`** 체크를 권합니다. 브이월드가 활용사례로 소개할 수 있다는 뜻이라
불이익이 없고, 심사에 오히려 도움이 됩니다.

## 신청 후

- 승인까지 **1~2일** 걸립니다. 이메일로 알림이 옵니다.
- 승인되면 `오픈API` → `인증키 관리` 에서 키를 확인합니다.
- 키는 아래에 등록합니다 (파일 아님).
  https://github.com/charlottebrown0904/traffic/settings/secrets/codespaces
  Name `VWORLD_KEY`

## 서비스URL 관련 주의

- 등록한 도메인 외에서 호출하면 인증 오류가 날 수 있습니다.
- 로컬이나 Codespaces 에서 수집 스크립트를 돌릴 예정이므로, 승인 후
  `인증키 관리` 에서 **`http://localhost` 를 추가 등록**해두면 안전합니다.
- 서버 사이드 호출은 보통 도메인 제한을 받지 않지만, 막히면 이 항목을 먼저 보세요.
