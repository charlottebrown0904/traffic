# 역할 분담 — 사용자가 할 일 / Claude 가 할 일

## 가르는 기준

**사용자만 할 수 있는 일**은 대체로 이 넷 중 하나입니다.

| 유형 | 예 |
|---|---|
| 신원·자격이 필요한 것 | 계정 가입, 사업자등록, PG 계약, 공인중개사 자격 |
| 돈이 걸린 것 | 결제 수단 등록, 요금제 선택, 도메인 구매 |
| 법적 책임이 따르는 것 | 약관 확정, 개인정보처리방침 게시, 변호사 검토 |
| 사업 판단 | 가격 정책, 대상 지역, 출시 시점 |

**Claude 가 할 수 있는 일**은 코드·스키마·테스트·문서·마이그레이션·정책 초안입니다.
계정 없이 만들 수 있는 것은 전부 미리 만들어 두고, 키만 꽂으면 돌게 해둡니다.

> 🔑 **키 전달 원칙**: `anon key` 처럼 공개용으로 설계된 값은 알려주셔도 됩니다.
> `service_role key`, PG 시크릿, DB 비밀번호는 **절대 채팅에 붙여넣지 마세요.**
> 저는 그 값을 참조하는 코드만 쓰고, 값 자체는 GitHub Secrets 나 배포 환경변수에
> 사용자가 직접 넣습니다.

## 아키텍처 권장안

지금은 **FastAPI + SQLite** 로 매물 API 가 돌아갑니다 ([listings-api.md](listings-api.md)).
Supabase 로 옮기는 것을 권합니다. 이유는 세 가지입니다.

1. **PostGIS** — 지금 파이썬으로 계산하는 거리·반경을 DB 가 인덱스로 처리합니다.
   매물이 늘어날수록 차이가 커집니다.
2. **RLS(Row Level Security)** — "타인의 매물은 조회조차 안 된다"를 애플리케이션이 아니라
   **DB 가 강제**합니다. 지금 짜둔 13개 보안 테스트가 그대로 RLS 정책 명세가 됩니다.
3. **서버 운영이 없어짐** — 정적 호스팅 + Supabase 면 상시 켜둘 서버가 없습니다.
   1인 운영에서 이게 가장 큽니다.

```
현재                              권장
────────────────────────────────────────────────────────────
브라우저                          브라우저
   ↓                                 ↓ supabase-js (RLS 적용)
FastAPI (상시 가동 필요)          Supabase (Postgres + PostGIS + Auth + Storage)
   ↓                                 ↑
SQLite                            GitHub Actions (수집·분석 배치)
                                     ↑
                                  Python 파이프라인 (그대로 유지)
```

**Python 분석 파이프라인은 그대로 둡니다.** 수집·헤도닉·상관분석은 배치 작업이고,
결과만 Supabase 에 밀어 넣으면 됩니다. 지금까지 만든 것은 버려지지 않습니다.

## 순서 — 무엇이 무엇을 막고 있나

```
A1~A4 (API 키)  ─┬─> A5 probe-history ──> A6~A7 수집 ──> 분석 ──> 스코어
                 │
B1~B7 (Supabase) ─┴─> B9~B15 이관 ──> D (배포) ──> 공개
                                          │
C1~C3 (Secrets) ──> C4~C9 자동화 ─────────┘
                                          │
E1~E5 (사업자·PG) ──> E6~E9 결제 ─────────┴──> 과금 시작
                                          │
F1~F2 (자격 정책) ──> F3~F4 검증 ─────────┘
```

**병렬로 가능합니다.** A(데이터)와 B(Supabase)는 서로를 기다리지 않습니다.
E(결제)는 사업자등록이 오래 걸릴 수 있으니 **일찍 시작**하는 게 낫습니다.
