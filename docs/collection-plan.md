# 인자 자료 수집 계획 — 누가 무엇을 (2026-09-14)

지시: 31개 인자 중 검증할 수 있는 것은 진행하고 필요한 자료는 직접 수집하라.
사용자만 할 수 있는 것은 수집 방법을 적어라.

원칙: **키만 있으면 되는 것은 내가 한다.** 포털 파일은 로그인 없이
중계기로 받힌다(5차 탐침). 사용자 몫은 셋뿐이다 — (1) 계정으로만 되는
활용신청·인증키 발급, (2) 회원 전용 파일 내려받기, (3) 사람이 읽어야 하는
고시·발표를 원장에 적는 일.

## 2. 사용자만 할 수 있는 것 — 방법까지

### A. 공공데이터포털 활용신청 (같은 계정 · 같은 키 · 자동 승인)

로그인 → 검색 → 데이터셋 화면의 **활용신청** → 활용목적 '참고자료' → 신청.
승인되면 "신청했다" 한 줄과 **데이터셋 번호**(주소의 /data/번호/)만 주면 된다.

| 인자 | 검색어 | 무엇을 신청하나 |
|---|---|---|
| 사업체·고용 | `고용보험 피보험자` · `시군구 사업체` | 고용노동부의 시군구·월 피보험자 API. 후보가 여럿이라 **번호를 알려 달라** — 내가 추측해 틀린 표를 받지 않기 위해 |
| 산업단지 (API 판) | `산업단지 현황` (한국산업단지공단) | 파일(15041930)이 먼저다. 파일에 지정일·주소가 없을 때만 API 를 신청 |
| 철도역 | `철도역 위치` · `역사 좌표` (국가철도공단) | 파일형이 있으면 신청 없이 받는다. API 만 있으면 신청 |
| 지방세 세목별 | 지방재정365 OpenAPI 목록에서 이름에 `세목` 또는 `지방소득세` | 총액(DFGDGG)을 세목별로 바꾸는 열쇠. **표 이름과 요청주소(/lf/hub/…)** 만 주면 된다 |

### B. 인증키 발급 → Vercel 환경변수 (값은 채팅에 붙이지 않는다)

| 키 | 어디서 | Vercel 이름 | 무엇에 |
|---|---|---|---|
| R-ONE | www.reb.or.kr/r-one/portal/openapi (신청은 끝남) | `REB_KEY` | 지가변동률 — 시장 층 · 시점수정. probe 가 '키 없음' 이면 이것이 원인 |
| KOSIS | kosis.kr → 공유서비스 → OpenAPI → 인증키 신청 (무료·즉시) | `KOSIS_KEY` | 인구 순이동 · 사업체조사 자동화 (지금은 파일) |
| OpenDART | opendart.fss.or.kr → 인증키 신청 (무료·즉시) | `DART_KEY` | 대기업 신규시설투자 공시 — 사건 인자 원천 |

넣은 뒤 **재배포**(Vercel 이 자동으로 한다 — main 에 푸시가 있을 때). 중계기
규칙은 내가 더한다.
