# 실측 3차 — 영업소 보강 후 (2026-09-02, analyze run 7)

지시 1~3의 답입니다. 계수는 로그에서 그대로 옮겼고, 해석은 제가 붙였습니다.

## 0. 표본이 어떻게 달라졌나

영업소 보강으로 **401 → 442개**가 됐습니다. 민자고속도로 좌표를 이름으로
찾아 넣었고, 시도·시군구도 좌표로 되짚어 채웠습니다. 순위표에 '미상' 대신
'평택시', '용인시 기흥구' 가 찍히기 시작한 게 그 결과입니다.

패널은 1,733 → 1,817행. 다만 **위약 밴드는 오히려 얇아졌습니다** (14개 →
11개 영업소, 104 → 89행). 새 영업소가 생기면 어떤 땅의 '가장 가까운 IC' 가
바뀌므로, 10-20km 에 있던 거래가 가까운 밴드로 옮겨 간 것입니다. 자료가
나빠진 게 아니라 지형을 더 정확히 반영한 결과이고, 그만큼 **위약 검정은
더 어려워졌습니다.**

## 1. 지시 2 — 신규 개통 영업소 전후 지가 (이중차분)

```
개통이 확인된 영업소 전국 73개 (2018~2025)
표본
  treated post   거래  영업소  시군구   평균ln단가
        0    0  4,025    20      5     12.436
        0    1  6,081    28      7     12.535
        1    0  1,115    11      7     12.750
        1    1  1,224    13      8     12.850

처치 영업소 13개 · 처치 거래 2,339건

DiD  처치×개통후 = +0.0772 (se 0.1446, t +0.53, p 0.5934)
                → 대조군 대비 +8.0%

상대연도별 (기준 = 개통 직전 해)
  -2  -0.184  (p 0.171)
   0  -0.061  (p 0.796)
  +1  -0.203  (p 0.163)
  +2  +0.264  (p 0.291)
```

**결론: 이 자료로는 개통 효과를 확인할 수 없습니다.**

점추정은 +8% 로 통념과 같은 방향이지만, 표준오차가 0.14 라 95% 구간이
대략 **-19% ~ +43%** 입니다. 0 을 한참 품고 있습니다. p=0.59 는 "효과가
없다" 가 아니라 **"있는지 없는지 말할 수 없다"** 입니다. 이 둘을 섞으면
안 됩니다.

상대연도별 부호도 오락가락합니다(+1년 -0.20, +2년 +0.26). 진짜 효과가
있다면 개통 후에 꾸준히 한 방향이어야 합니다.

좋은 소식 하나: **개통 전 계수(-2년)가 유의하지 않습니다.** 평행추세
가정은 이 표본에서 버팁니다. 설계가 틀린 게 아니라 표본이 모자란 것이라,
표본이 늘면 이 설계 그대로 다시 물어볼 수 있습니다.

왜 얇은가: 거래 수집이 2021년부터라, 그 전에 개통한 평택고덕(2018)·
양감(2019)·중앙탑(2019)은 개통 전 자료가 없습니다. 반대로 2024년 말~
2025년 초 개통분(하남감북·강동고덕·북양주·서양주·안성맞춤 등 다수)은
개통 후가 한 해뿐입니다. 실제로 전후가 다 있는 것은 남사진위(2022)·
두물머리·조안·아산 계열·시화(2023)·청주강서(2024) 정도입니다.

**늘리는 방법:** 거래 수집 시작을 2018년으로 당기면 평택고덕·양감·중앙탑이
살아나고, 2026년 자료가 쌓이면 2024~25년 개통분의 사후 기간이 생깁니다.
표본을 늘리려고 밴드를 넓히거나 최소 거래건수를 낮추는 것은 하지 않습니다.

## 2. 지시 3 — IC 교통량 순으로 세워 주변 지가 비교

기준연도 2025 · 반경 0~5km · **IC 44개** (IC 당 거래 30건 이상)

### 전체 교통량

```
순위 상관 (Spearman) +0.520

   모형   n    beta     se      t       p      r2
  raw    44  +0.333  0.118   2.82  0.0048  0.243
+서울거리 44  +0.239  0.091   2.62  0.0089  0.628
  시도내  44  +0.306  0.111   2.76  0.0058  0.368
```

교통량이 10% 많은 IC 주변 땅이 3.3% 비쌉니다. 서울거리를 통제하면 2.4%
로 **28% 줄지만 여전히 유의**합니다. 시도 안에서만 비교해도 3.1% 로 거의
그대로입니다.

즉 이 상관은 "전부 서울 가까워서" 는 아닙니다. 다만 **횡단 비교라 인과가
아닙니다.** 비싼 곳에 IC 를 놓았을 가능성이 그대로 남아 있고, 그걸 가르는
것이 지시 2 인데 위에서 봤듯 아직 답을 못 냅니다.

### 화물 교통량 — 여기가 흥미롭습니다

```
순위 상관 (Spearman) +0.103

   모형   n    beta     se      t       p      r2
  raw    44  +0.071  0.061   1.17  0.242   0.025
+서울거리 44  +0.100  0.037   2.73  0.0064  0.558
  시도내  44  +0.065  0.061   1.06  0.289   0.186
```

**통제 전에는 유의하지 않다가(p=0.24) 서울거리를 넣자 유의해집니다(p=0.006).
계수도 줄지 않고 오히려 41% 커집니다.**

이건 억제 효과입니다. 서울에서 멀수록 화물 비중이 높고, 서울에서 멀수록
땅값은 쌉니다. 두 방향이 반대라 통제 전에는 서로를 가리고 있었습니다.
거리를 빼주고 나서야 "같은 거리라면 화물이 많이 다니는 IC 주변이 비싸다"
가 보입니다.

**실무적으로 이게 순위표보다 중요합니다.** 화물 교통량 순위표만 보면
평택·안성·이천이 위에 오는데(서울에서 먼 곳), 그건 화물 효과가 아니라
그냥 "외곽에 물류가 몰린다" 입니다. 같은 거리끼리 비교해야 신호가 나옵니다.
화면의 순위표 아래에 이 경고를 적어 둔 이유입니다.

## 3. 밴드별 탄력성 (참고) — 달라지지 않았습니다

```
[land] volume_total   0-1 -1.42(p=0.09) · 1-3 -0.95(p=0.44) · 3-5 -0.61(p=0.14) · 5-10 +0.62(p=0.52)
[land] volume_freight 0-1 -0.78(p=0.04) · 1-3 -0.40(p=0.34) · 3-5 -0.25(p=0.21) · 5-10 +0.11(p=0.48)
```

**위약 밴드 10-20km 는 여전히 추정하지 못했습니다(30행).** 그래서 위 계수를
IC 효과로 읽을 수 없습니다. 이건 반복해서 적어 둡니다 — 거리 사다리가
그럴듯해 보인다는 이유로 위약 검정을 건너뛰는 것이 이 분석에서 가장 하기
쉬운 실수입니다.

공장(factory)은 어느 밴드도 추정 불가입니다(최대 24행).

## 4. 그래서 지금 말할 수 있는 것

1. **교통량이 많은 IC 주변 땅이 비싸다** — 서울거리를 통제해도 남습니다. (횡단, 인과 아님)
2. **화물은 같은 거리끼리 비교해야 신호가 보인다** — 순위표만 보면 놓칩니다.
3. **IC 가 새로 생기면 주변 땅값이 오르는가** — 이 자료로는 아직 모릅니다.
   방향은 +8% 지만 구간이 -19%~+43% 입니다.
4. **거리 사다리(가까울수록 큰 계수)는 아직 위약 검정을 통과하지 못했습니다.**

투자 판단에 쓰려면 3번이 필요한데, 그게 아직 없습니다. 화면에서 순위를
'저평가 후보' 로 부르는 것을 조심해야 하는 이유입니다.
