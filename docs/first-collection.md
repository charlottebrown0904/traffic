## 확인된 것

**지오코딩 성공률 100%.** 실패 0건. 그중 **88%가 지번단위**로 떨어졌다.
토지 거래는 지번이 가려져(`5*`) 법정동 중심점으로 밀릴 것을 우려했는데,
브이월드가 부분 지번으로도 상당수를 필지 단위까지 찾아냈다.
0-3km 근거리 밴드를 쓸 수 있다는 뜻이다.

**응답 필드가 설계대로 온다.** `jimok`(지목), `landUse`(용도지역),
`dealAmount`(만원), `dealArea`(㎡) — 헤도닉 통제변수가 모두 들어 있다.

## 남은 것

**교통량이 0이라 분석·화면 단계가 돌지 않는다.** panel 은 거래와 교통량을
연도별로 붙이는데 교통량이 없으니 만들 재료가 없다. 이것이 지금 유일한 병목이다.

서울 경유 탐색으로 엔드포인트는 찾았다:

```
odtraffic/trafficAmountByUnit    영업소별 교통량
  → "필수요청 파라메터(집계시간단위구분코드)가 없습니다"
odtraffic/trafficAmountByRoute   노선별
  → "시작영업소 값이 없습니다"
```

파라미터 이름만 확정하면 된다. (P2-3)
