# 부동산통계정보(R-ONE) Open API — 무엇을 쓸 수 있나 (2026-09-12)

요청: "부동산통계정보 사이트 api 신청 완료. 이용 가능한 것이 있는
지 확인 바랍니다." 올려 주신 파일 다섯 개를 다 읽었습니다. 결론부터:

> **네, 있습니다. 시점수정의 원천이 여기 있습니다.**
> 그리고 예상 밖의 것 두 개가 더 나왔습니다 — **순수토지 거래량**과
> **역세권 지가지수**입니다. 요청제한횟수는 **없습니다**(명세서 기재).

올려 주신 파일이 무엇이었는지:

| 파일 | 실제 내용 |
|---|---|
| `OpenAPI_____.xls` | 확장자는 xls, 실제로는 **HTML 표** — 통계표 목록 **635개** |
| `______________API___.xls` | 명세서 — 서비스 통계목록 (`SttsApiTbl`) |
| `_____________API___.xls` | 명세서 — 통계 세부항목 (`SttsApiTblItm`) |
| `___________API___.xls` | 명세서 — 통계 조회 (`SttsApiTblData`) |
| `1789231346981___________.xls` | 진짜 옛 엑셀(BIFF8) — **토지가격비준표** 주거지역 한 장 |

마지막 것은 R-ONE API 와 무관한 별개의 수확이라 따로 적었습니다 →
`docs/bijunpyo.md`.

## 1. API 의 모양 — 세 개가 한 줄로 이어진다

```
SttsApiTbl      https://www.reb.or.kr/r-one/openapi/SttsApiTbl
SttsApiTblItm   https://www.reb.or.kr/r-one/openapi/SttsApiTblItm
SttsApiTblData  https://www.reb.or.kr/r-one/openapi/SttsApiTblData
```

세 개 모두 기본인자가 같습니다.

| 변수 | 값 |
|---|---|
| `Key` | 인증키 (**대문자 K**) |
| `Type` | `xml` 또는 `json` |
| `pIndex` | 페이지 위치 (1부터) |
| `pSize` | 페이지당 건수 — **최대 1,000** (넘기면 오류 336) |

요청인자와 주요 출력값:

| 엔드포인트 | 필수 | 선택 | 주요 출력 |
|---|---|---|---|
| `SttsApiTbl` | — | `STATBL_ID` | `STATBL_ID` `STATBL_NM` **`DTACYCLE_CD`** `DATA_START_YY` `DATA_END_YY` `OPEN_STATE` `RPSTUI_NM`(기준시점) |
| `SttsApiTblItm` | `STATBL_ID` | `ITM_TAG` | `ITM_ID` `PAR_ITM_ID` `ITM_NM` `ITM_FULLNM` `UI_NM` |
| `SttsApiTblData` | `STATBL_ID` `DTACYCLE_CD` | `WRTTIME_IDTFR_ID` `GRP_ID` `CLS_ID` `ITM_ID` `START_WRTTIME` `END_WRTTIME` | `GRP_NM`(대개 시도) `CLS_NM`(대개 시군구) `ITM_NM` **`DTA_VAL`** `UI_NM` `WRTTIME_DESC` |

메시지 코드 중 **꼭 구분해야 하는 둘**:

- `290` 인증키가 유효하지 않음 → 중계기의 `REB_KEY` 문제.
- `200` **해당하는 데이터가 없음 — 오류가 아닙니다.** 조건에 맞는 칸이
  빈 것뿐입니다. 이것을 예외로 던지면 빈 칸이 많은 시군구에서 수집이
  통째로 멈춥니다 (`src/redt/collect/reb.py` 는 구분해 다룹니다).

### 함정 하나 — 주기코드를 추측하지 않는다

`SttsApiTblData` 는 `DTACYCLE_CD` 를 **필수**로 받는데 명세서에 코드값 표가
없습니다. 틀린 값을 넣으면 오류가 아니라 **`200` 자료 없음**이 옵니다.
그러면 "이 표에는 자료가 없구나" 로 읽습니다 — RTMS 시군구 코드에서 이미
같은 함정에 빠진 적이 있습니다(잘못된 코드에 0건이 옵니다).

그래서 `cycle_of()` 가 **`SttsApiTbl` 목록에서 읽어 옵니다.** 코드에
`"MM"` 같은 값을 적어 넣지 않았습니다.

## 3. 길 — 코드와 워크플로

```
src/redt/collect/reb.py       세 엔드포인트 + TABLES(우리가 고른 20개 표)
scripts/reb_stats.py          --probe / --items ID / --pull 이름
.github/workflows/reb-stats.yml   Actions → '지가변동률 수집'
```

이 상자(미국 러너)에서는 `www.reb.or.kr` 로 직접 나갈 수 없습니다. 서울
중계기(`api/relay.js`)를 거칩니다 — ALLOW 에 이미 있었고, 이번에
**인증키 주입**을 붙였습니다.

```js
"www.reb.or.kr": { param: "Key", env: "REB_KEY", optional: true },
```

`optional: true` 인 이유: 같은 호스트가 **키 없는 공개 화면 읽기**에도
쓰입니다(`scripts/reb_probe.py`). 키가 아직 없으면 500 으로 막지 않고
통과시켜, 키를 받기 전에도 화면 탐침이 계속 됩니다.

## 4. 필요한 것 (사용자) — 한 가지

**Vercel 환경변수에 `REB_KEY` 를 넣어 주십시오.**

- Vercel → 이 프로젝트(토지 고고) → Settings → Environment Variables
- Name: `REB_KEY`, Value: R-ONE 에서 발급받은 인증키
- Production 에 체크 → Save → **재배포**(환경변수는 새 배포에만 붙습니다)

**키를 여기(대화)에 붙이지 마십시오.** 중계기만 알면 되고, 저는 몰라도
됩니다 — 지금까지의 모든 키가 그렇게 되어 있습니다.

넣으신 뒤 Actions → **지가변동률 수집** → mode `probe` 를 한 번 누르시면,
20개 표가 다 있는지·주기코드가 무엇인지·자료가 몇 년부터인지 찍습니다.
그 출력을 보고 `--pull` 로 넘어갑니다.

## 5. 아직 말할 수 없는 것

정직하게 적습니다. 키가 없어 **한 번도 호출해 보지 못했습니다.**

1. **응답을 감싸는 모양** — 명세서는 출력 *항목*만 적고 봉투를 적지
   않았습니다. 기본인자(`Key`/`Type`/`pIndex`/`pSize`)가 서울 열린데이터
   광장과 같은 계열이라 `{"SttsApiTblData":[…,{"row":[…]}]}` 일 것이
   거의 확실하지만, 확실하지 않습니다. 그래서 파서를 그 모양에 못박지
   않고 **응답을 훑어 `row`/`RESULT` 를 찾습니다** (`reb._walk`).
2. **주기코드의 실제 값** — 목록에서 읽습니다(위 §1 함정).
3. **시군구까지 쪼개지는가** — `GRP_NM`/`CLS_NM` 이 시도/시군구일 것으로
   보이지만 표마다 다를 수 있습니다. `--probe` 뒤 `--items` 로 봅니다.
4. **일별 트래픽 제한** — 명세서에 "요청제한횟수 제한없음" 이라 적혀
   있으면서 오류 코드에는 `337 일별 트래픽 제한`이 있습니다. 둘 중 무엇이
   맞는지는 실제로 많이 불러 봐야 압니다. 그래서 수집기는 한 표씩,
   기간을 끊어 받습니다.
