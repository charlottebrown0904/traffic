# 도로공사 포털 원본을 올리는 자리

`https://data.ex.co.kr` 에서 받은 **영업소별 차종별 교통량** 파일을 그대로 넣습니다.
가공하지 마세요 — 합치고 정규화하는 것은 `scripts/convert_tcs_annual.py` 가 합니다.

## 파일 이름

받은 이름 그대로 두셔도 되지만, 연도가 이름에 없으면 무엇인지 알 수 없습니다.
연도(와 월)를 붙여주세요.

```
tcs_2024.xlsx          연간 파일이면 이렇게
tcs_2024_03.xlsx       월별 파일이면 이렇게
```

## 필요한 범위

거래가 2016~2025 이고 교통량은 1년 시차로 보므로 **2015~2025** 가 최종 목표입니다.
다만 **첫 검증에는 3년이면 충분합니다** — 2022·2023·2024 부터 올려주세요.
파이프라인이 도는지, 밴드별 계수가 어느 방향으로 나오는지 먼저 보고 넓힙니다.

## 이미 있는 것

`data/raw/tcs_annual_2025.csv` — 2025년 (2,850행, 영업소 475개, 차종 6종)
