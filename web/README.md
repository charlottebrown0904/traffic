# 웹 화면

DB 에 직접 붙지 않습니다. `web/data/*.json` 만 읽으므로
합성 데이터든 실데이터든 화면 코드는 동일합니다.

```bash
make web        # JSON 생성 + 로컬 서버 (http://localhost:8000)
make serve      # JSON 이 이미 있을 때 서버만
```

> `index.html` 을 파일로 직접 열면(`file://`) 브라우저가 fetch 를 차단합니다.
> 반드시 로컬 서버로 여세요.

## 화면 구성

| 탭 | 내용 |
|---|---|
| **탐색** | 지도 · 영업소 마커(분면별 색) · 거리 밴드 · 실거래 점 · 우측 상세 패널 |
| **스코어보드** | 교통량 × 가격 모멘텀 2×2 산점도 + 영업소 순위표 |
| **매물** | 중개사 매물 등록 폼 + 목록 (형식 확인용, 브라우저에만 저장) |

## 데이터 파일

| 파일 | 내용 |
|---|---|
| `meta.json` | 생성 시각, **합성 데이터 여부**, 기간, 밴드 정의, 면책 문구 |
| `tollgates.json` | 영업소 좌표 + 스코어 + 분면 |
| `trades.json` | 지도 표시용 실거래 표본 (최대 8,000점) |
| `series.json` | 영업소별 연도 시계열 (상세 패널·차트용) |

`meta.is_synthetic` 이 참이면 화면 상단에 **데모 데이터** 배너가 뜹니다.
실데이터로 교체하면 자동으로 사라집니다.

## 아직 비어 있는 것

- 지도 타일: OpenStreetMap 공개 타일 사용 중 (상용 시 별도 계약 필요)
- 매물 등록: **브라우저 localStorage** 에만 저장. 서버·DB·결제 미연동
- 중개사 등록번호: 형식(`00000-0000-00000`)만 검사. 실제 자격 검증 미연동
- 로그인·권한: 없음
